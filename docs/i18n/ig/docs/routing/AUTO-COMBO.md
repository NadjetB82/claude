## Ntụgharị-Ụzọ Akpaaka Na-Enweghị Nhazi (`auto/` prefix)

> **IHE ỌHỤRỤ:** Ọ dịghị mkpa ịmepụta combo. Jiri `auto/` prefix ozugbo n'ime client ọ bụla.

### Ọmụmaatụ Ngwa Ngwa

| ID Model       | Ụdị     | Omume                                                                                     |
| -------------- | ------- | ----------------------------------------------------------------------------------------- |
| `auto`         | ndabara | Ndị na-eweta ọrụ niile ejikọrọ, atụmatụ LKGP, arọ ndị ahaziri nhata                       |
| `auto/coding`  | coding  | Arọ ndị na-ebute ogo ụzọ, dabara maka imepụta koodu                                       |
| `auto/fast`    | fast    | Nhọrọ nwere arọ na obere latency                                                          |
| `auto/cheap`   | cheap   | Ntụgharị-ụzọ ahaziri iji belata ọnụ ahịa (ọnụ ahịa kacha ala na mbụ)                      |
| `auto/offline` | offline | Na-akwado ndị na-eweta ọrụ nwere oke ojiji kacha dị ukwuu                                 |
| `auto/smart`   | smart   | Ogo ụzọ + ọnụego nyocha dị elu (10%) iji chọpụta model ka mma                             |
| `auto/lkgp`    | lkgp    | LKGP akọwapụtara kpọmkwem (otu ihe ahụ dị ka `auto` ndabara)                              |
| `auto/chaos`   | chaos   | Mgbasa yiri ibe ya, otu model maka onye na-eweta ọrụ ọ bụla (ọ bụghị itinye nsogbu n'ọrụ) |

### Ngwakọta Otu × Ọkwa (`auto/<category>:<tier>`)

Suffix ndị yiri nke OpenRouter na-ekewa **ụdị ụzọ ọ bụ** (otu) na **otu esi ahazi ya nke ọma** (ọkwa), ka ị nwee ike ijikọta ha n'enweghị mgbochi (#4235 Phase B, `open-sse/services/autoCombo/suffixComposition.ts`):

- **Otu dị iche iche** (na-enyocha ọdọ ndị a ga-ahọrọ dịka ike ha si dị): `coding` · `reasoning` · `vision` · `chat` · `multimodal`. `vision`/`multimodal` na-edobe model ndị nwere ike vision; `reasoning` na-edobe model ndị nwere ike reasoning/thinking.
- **Ọkwa dị iche iche** (na-ahọrọ arọ akara / ihe nzacha ọdọ): `fast` (zipụ-ngwa-ngwa) · `cheap` (aha ọzọ bụ `floor`, onye na-echekwa ọnụ ahịa) · `reliable` (ahụike circuit-breaker + nkwụsi ike latency) · `free` / `pro` (na-eji `classifyTier` enyocha ọdọ ahụ dịka ọkwa model si dị — ọkwa efu megide nke premium).

| Ọmụmaatụ               | Na-aghọ                                                             |
| ---------------------- | ------------------------------------------------------------------- |
| `auto/coding:fast`     | ọdọ coding, arọ nwere obere latency                                 |
| `auto/coding:cheap`    | ọdọ coding, nke ahaziri maka ọnụ ahịa (aha ọzọ `auto/coding:floor`) |
| `auto/reasoning:pro`   | naanị model reasoning/thinking, ọkwa premium                        |
| `auto/vision`          | model ndị nwere ike vision (enweghị ọkwa → arọ ndị ahaziri nhata)   |
| `auto/multimodal:free` | model ndị nwere ike multimodal, naanị ọkwa efu                      |

`auto/<category>[:<tier>]` ọ bụla ziri ezi na-edozi mgbe achọrọ ya; a na-egosi obere nchịkọta a họpụtara nke ọma na `/v1/models` nakwa na dashboard (`AUTO_SUFFIX_VARIANTS` dị na `open-sse/services/autoCombo/builtinCatalog.ts`). Nzacha a bụ **fail-open** — ọ bụrụ na iwu enweghị model ejikọrọ ọ bụla dabara na ya, a ga-eji ọdọ niile ka ntụgharị-ụzọ ghara ịkwụsị ịrụ ọrụ. Onye isi na-enye akara (`combo.ts`) agbanwebeghị; a na-etinye ihe nzacha otu/ọkwa n'ime `buildAutoCandidates`.

> **Ọgụgụ isi model ozugbo:** ọkwa **Arena ELO** ndị dị ugbu a + data ọkwa **models.dev** na-enye aka n'ịtụ ịdị mma nke ntụgharị-ụzọ akpaaka mgbe flag `ARENA_ELO_SYNC_ENABLED` dị ọkụ (ma ọ bụghị ya, ọ na-alaghachi na map ịdị mma static).

**Otu esi eji ya:**

```bash
# Any IDE or CLI tool that supports OpenAI format
Base URL: http://localhost:20128/v1
API Key:  <your-endpoint-key>

# In your code/config, set model to:
model: "auto"                 # balanced default
model: "auto/coding"          # best for coding tasks
model: "auto/fast"            # fastest available
model: "auto/cheap"           # cheapest per token
```

**Ihe na-eme:**

1. OmniRoute na-achọpụta `auto/` prefix n'ime `src/sse/handlers/chat.ts`
2. Na-ajụ nchekwa data maka **njikọ ndị na-eweta ọrụ niile nọ n'ọrụ**
3. Na-enyocha ma hapụ naanị ndị nwere nzere ziri ezi (API key ma ọ bụ OAuth token)
4. Na-ekpebi model maka njikọ ọ bụla (`connection.defaultModel` ma ọ bụ model mbụ nke onye na-eweta ọrụ)
5. Na-ewulite **virtual combo** n'ime ebe nchekwa (anaghị echekwa ya na DB)
6. Na-eme ntụgharị-ụzọ site na iji profaịlụ arọ nke ụdị ahọpụtara + atụmatụ LKGP

**Njirimara ndị bụ isi:**

- ✅ **Na-arụ ọrụ mgbe niile:** Enweghị toggle, enweghị imepụta combo, enweghị nhazi achọrọ
- ✅ **Na-agbanwe agbanwe:** Na-egosipụta ndị na-eweta ọrụ ejikọrọ ugbu a na-akpaghị aka
- ✅ **Ịrapara na session:** LKGP na-ahụ na a na-ebute onye na-eweta ọrụ ikpeazụ rụrụ nke ọma ụzọ
- ✅ **Na-aghọta ọtụtụ account:** Njikọ onye na-eweta ọrụ ọ bụla na-aghọ candidate dị iche
- ✅ **Enweghị ide na DB:** Virtual combo dị naanị maka request ahụ, enweghị ibu persistence ọ bụla

### Njikwa candidate nke igodo ọ bụla (#7819, Ọkwa 1+2)

`GET /v1/auto-combo/{channel}/candidates` (`{channel}` = suffix na-esote `auto/`, ma ọ bụ
`auto` kpọmkwem maka channel bụ isi) bụ endpoint **naanị maka ịgụ** nke na-edepụta
ọdọ candidate dị ugbu a nke channel `auto/*`, tinyere ozi nnweta ozugbo, site n'iji
ọgụgụ resilience ndị dị ugbu a emegharị (ọ bụghị breaker `state` raw):

- circuit breaker nke onye na-eweta ọrụ — `getCircuitBreaker(provider).getStatus()` / `.canExecute()`
- cooldown nke njikọ — `rateLimitedUntil` / `testStatus` n'ahịrị
  `provider_connections` e kpebiri
- mkpọchi model — `isModelLocked(provider, connectionId, model)`

Candidate ọ bụla nwekwara flag `excluded` nke API key a. A na-echekwa mwepu
maka API-key ọ bụla (`auto_candidate_overrides` table, migration `128`) — OmniRoute bụ
single-tenant na-enweghị table `users`, ya mere `apiKeyId` bụ njirimara onye na-akpọ oku
kachasị nso n'ezie — a na-etinyekwa ya n'ọrụ n'ebe njedebe ọdọ candidate dị na
`open-sse/services/autoCombo/virtualFactory.ts` site na `filterExcludedCandidates()`
dị ọcha ma nwalee unit (`open-sse/services/autoCombo/candidateOverrides.ts`).
Ihe nzacha ahụ bụ **fail-open**: apiKeyId/channel a na-edobeghị ma ọ bụ ọdịda nchọta DB
ga-ahapụ ọdọ ahụ n'enweghị nzacha, ka onye nchịkwa na-enweghị override ọ bụla ahaziri
wee hụ ntụgharị-ụzọ nke byte ọ bụla yiri nnọọ nke dị tupu atụmatụ a.

**Ebugharịrị gaa n'okwu a ga-esochi:** ibu arọ nke onye ndọrọ ọ bụla + nhazi pořọdụ doro anya (Ọkwa 3
— na-abanye n'ụzọ atụmatụ ibu arọ/ebute ụzọ ndị dị ugbu a) na ịtụgide atụmatụ
`combo.ts` akọwapụtara maka channel `auto/*` ọ bụla (Ọkwa 4). Lee atụmatụ #7819 maka ajụjụ
ka ghe oghe gbasara ma overrides kwesịrị ịdịgide n'otu API key ọ bụla, ka ọ bụ bụrụ nke zuru ụwa ọnụ n'ihi
ụdị single-tenant ahụ.

**Ihe na-eme n'azụ:**

```txt
Request: { model: "auto/coding" }
   ↓
src/sse/handlers/chat.ts detects prefix
   ↓
createVirtualAutoCombo('coding') → candidatePool from active connections
   ↓
handleComboChat (same engine as persisted combos)
   ↓
Auto-scoring selects best provider/model per request
```

## Aha Combo Ndị Dabara na Ezigbo Model Id

Combo nke `name` ya bụ otu ihe kpọmkwem na model id nkịtị (dịka ọmụmaatụ, combo a kpọrọ
`gpt-5.5`) bụ **usoro e bu n’obi ma na-akwado**, ọ bụghị ntụpọ: ọ bụ
usoro eji eme ndabere provider maka model-id ọ bụla nke akọwara na
[#6940](https://github.com/diegosouzapw/OmniRoute/issues/6940). Ebe ọ bụ na a na-ebu ụzọ elele
mkpebi combo tupu mkpebi bare-model-id
(`getComboForModel()` dị na `src/sse/services/model.ts`), a na-eziga arịrịọ maka id nkịtị
`gpt-5.5` site na targets nke combo ahụ (dịka ọmụmaatụ
`acme-responses/gpt-5.5`, `backup-responses/gpt-5.5`) kama iziga ya ozugbo na
otu provider — nke a na-eji ọzọ combo-before-rewrite precedence e wuru maka
[#3227/#3233](https://github.com/diegosouzapw/OmniRoute/issues/3227), a na-ejikwa
`tests/unit/responses-combo-resolution-3227.test.ts` na
`tests/unit/combo-name-codex-responses-rewrite.test.ts` nwalee ya iji gbochie regression.

A naghị **ajụ ma ọlị** imepụta combo ma ọ bụ ịgbanwe aha ya ka ọ bụrụ aha na-ekpuchi ezigbo model id — ime nke ahụ ga-emebi usoro ọrụ a edekọtara. Kama nke ahụ
(#8530), `POST /api/combos` na `PUT /api/combos/[id]` na-agbakwunye field
`warning` nke na-adịghị egbochi ọrụ na response mgbe aha (ọhụrụ) ahụ dakọtara na ezigbo
model id:

```json
{ "warning": { "code": "COMBO_NAME_SHADOWS_MODEL", "modelId": "gpt-5.5", "providerId": "openai" } }
```

Mgbe usoro na-ebido, `scanComboModelNameCollisionsAtBoot()`
(`src/instrumentation-node.ts`) na-edekwa ịdọ aka ná ntị `[STARTUP]` nke otu ahịrị
nke na-edepụta combo niile dị adị na-ekpuchi model id, ka ndị na-ahụ maka sistemụ
ndị zutere nke a na mberede (kama ime ya n’ebumnobi, dịka #6940 si kwuo) nwee ihe ngosi.
Helper nchọpụta ahụ dị na `src/lib/combos/modelNameCollision.ts`.

## Ịkpọ Custom Combo Site na Client

A na-eji combos echekwara (Ntọala → Combos) naanị mgbe client zigara **aha combo ahụ kpọmkwem** na field `model` — enweghị fuzzy matching ma ọ bụ partial matching nke aha combo ahụ, a naghịkwa eji prefix `auto/`. Usoro mkpebi (`getComboForModel()` dị na `src/sse/services/model.ts`):

1. ndakọrịta aha combo kpọmkwem (`model: "my-combo"`),
2. prefix `combo/<name>` (`model: "combo/my-combo"`),
3. model→combo glob mappings (`/api/model-combo-mappings`).

```bash
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{"model":"my-combo","messages":[{"role":"user","content":"Hello"}]}'
```

Nsogbu abụọ a na-ahụkarị:

- **`auto` anaghị eji combos gị.** `auto`/`auto/*` na-ewu candidate pool nke ya na-achọghị nhazi ọ bụla, ọ na-elelekwa combos echekwara naanị ma ọ bụrụ na e nwere combo a kpọrọ `auto` kpọmkwem (anaghị atụ aro ya). Iji zipụ arịrịọ site na combo, ziga aha ya kpọmkwem — ọ bụghị `auto`.
- **`openrouter/auto` bụ ezigbo ngwaahịa OpenRouter a na-akwụ ụgwọ maka ya** ("Auto Best Available"), ọ bụghị alias OmniRoute. Ọ bụ otu static model entry dị na registry OpenRouter (`open-sse/config/providers/registry/openrouter/index.ts`), a na-akwụkwa ụgwọ ya iche. Jiri Ntọala → Routing → Zoo models a na-akwụ ụgwọ iji wepụ ya na `auto` pools.

Lee [#7992](https://github.com/diegosouzapw/OmniRoute/issues/7992) na [#7111](https://github.com/diegosouzapw/OmniRoute/issues/7111) maka mgbagwoju anya mbụ nke akwụkwọ a na-akọwa.

## Otu O Si Arụ Ọrụ (Persisted Auto-Combos)

Auto-Combo Engine na-eji **ọrụ ọnụọgụgụ akara nwere ihe 16 (16-factor scoring function)** (nke akọwapụtara na `open-sse/services/autoCombo/scoring.ts` → `DEFAULT_WEIGHTS`) ahọrọ onye na-eweta/ụdị kachasị mma maka arịrịọ ọ bụla n'ụzọ dị ike. Mkpokọta ịdị arọ ndabara na-eru `1.0`; a na-emegharị ịdị arọ omenala site na `normalizeScoringWeights()`. ## Atụmatụ Nduzi Nile

Igwe combo nke OmniRoute na-akwado **atụmatụ nduzi 20** (nke ekwuputara na `src/shared/constants/routingStrategies.ts` → `ROUTING_STRATEGY_VALUES`). Igwe Auto Combo n'onwe ya ka ekpughere n'okpuru atụmatụ `auto`; ndị ọzọ dị maka combo ndị echekwara.

| Atụmatụ             | Nkọwa                                                                                                                                                                                |
| :------------------ | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `priority`          | Ndepụta ahaziri ahazi nke ebumnuche mbụ nwere ihe kacha mkpa doro anya                                                                                                               |
| `weighted`          | Nhọrọ na-enweghị usoro dabere na ibu (weight) nke ebumnuche ọ bụla                                                                                                                   |
| `round-robin`       | Gbaa gburugburu ebumnuche n'usoro (n'ìgwè; lee n'okpuru)                                                                                                                             |

### Ụkpụrụ `weighted`

`weighted` bụ **nhọrọ na-enweghị usoro dabere na oke kwa arịrịọ**
(`open-sse/services/combo/targetSorters.ts` → `selectWeightedTarget`), ọ bụghị ihe nhata:

- Arịrịọ ọ bụla na-ese **otu** nzọụkwụ na ohere `weight / totalWeight`; nzọụkwụ ndị fọdụrụnụ ka ahaziri site na ibu na-agbada agbada dị ka usoro ndabere maka arịrịọ ahụ.
- Nzọụkwụ nke ibu ya bụ `0` (ma ọ bụ na-efu) **anaghị ese ya** mgbe nzọụkwụ ọ bụla ọzọ nwere ibu > 0 — ọ nwere ike ijere ozi dị ka ndabere mgbe nzọụkwụ a siri ike dara. Naanị mgbe **ihe niile** ibu bụ 0 ka nhọrọ na-aghọ otu.
- Nzọụkwụ ndị ebumnuche ha niile adịghị — onye na-eweta ọrụ circuit breaker `OPEN`, connection cooldown, model lockout — ka a na-ewepụ na eserese tupu ọ mee (`open-sse/services/combo/targetResolution.ts`), ya mere otu nzọụkwụ dị mma nwere ike imeri arịrịọ ọ bụla nwa oge.
- `stickyWeightedLimit` (combo config, ndabara `1` = gbanyụọ) na-ejikọta nzọụkwụ a siri ike maka ọtụtụ ihe ịga nke ọma na-esote tupu ịse ọzọ.

Maka ntụgharị siri ike jiri `round-robin`; ibu nha anya na `weighted` na-enye nguzozi ọnụ ọgụgụ — ọ bụghị nke siri ike.

### Ụdị pipeline nke onye nnọchi anya

Ngwakọta `pipeline` nwere opekata mpe ụdị abụọ nwere ike ịhọrọ ịbanye na ntụgharị onye na-eme atụmatụ/onye na-eme ihe (planner/executor) na `config.agenticOrchestration.enabled`. Ihe mgbaru ọsọ mbụ na-ahụ maka atụmatụ na azịza ikpeazụ; ihe mgbaru ọsọ nke abụọ na-ewepụta oku ngwaọrụ nke onye ahịa (client-native). OmniRoute na-achọpụta nsonaazụ ngwaọrụ na-aga n'ihu site na usoro arịrịọ, na-ajụ onye na-eme atụmatụ (planner) ma ọ bụrụ na ọ dị mkpa ọzọ maka ngwaọrụ, ma na-eme ka onye na-eme ihe (executor) ma ọ bụ onye na-eme atụmatụ (planner) bụrụ usoro ikpeazụ nke onye ahịa na-ahụ.

Nhọrọ `config.agenticOrchestration.contextCompaction` na-etinye mmefu ego payload dị iche tupu onye na-eme atụmatụ ma ọ bụ onye na-eme ihe ọ bụla ezipụ. Mee ka ọ rụọ ọrụ n'ụzọ doro anya:

```json
{
  "enabled": true,
  "defaultMaxChars": 400000,
  "targetRatio": 0.72,
  "toolResultMaxChars": 24000,
  "modelMaxChars": { "provider/planner": 175000, "provider/executor": 300000 }
}
```

Ndị a bụ mmefu ego agwa JSON a haziri ahazi nke onye ọrụ họọrọ, ọ bụghị windo gburugburu token ma ọ bụ oke elu nke ekwere nkwa. ID ụdị kpọmkwem na-emeri ndabara. N'elu ọnụ ụzọ ámá ahụ, compaction na-ewepụ nkọwa ngwaọrụ ndị yiri ya, na-egbutu ihe akaebe ngwaọrụ buru ibu na digest, ma na-ewepụ otu akụkọ ihe mere eme ochie zuru ezu gaa na oke ebumnuche. Ọ na-edobe ntuziaka sistemụ/onye mmepe, arịrịọ onye ọrụ kachasị ọhụrụ, gburugburu ngwaọrụ ikpeazụ gụnyere oku/nsonaazụ yiri ya, na ntuziaka ntụgharị na-eduga nke Gemini. A na-echekwa ntuziaka ọkwa kachasị elu na ntọala ngwaọrụ. Ihe nrịbama mwepu na-edekọ akụkọ ihe mere eme ewepụrụ; nke a bụ igbutu ihe doro anya, ọ bụghị nchịkọta semantiki. Ọ bụrụ na gburugburu ebe obibi a kọwara (pinned context) ka gafere mmefu ego, arịrịọ ahụ na-eweghachi 413 tupu ịkpọtụrụ ụdị ahụ. Site na compaction nwere nkwarụ ma ọ bụ n'okpuru ọnụ ụzọ ámá, arịrịọ ahụ na-agafe n'agbanweghị.

Ụdị ndị ọzọ mgbe ihe mgbaru ọsọ nke abụọ gasịrị bụ nkwado onye na-eme ihe (executor backups). Nzaghachi HTTP dara ada ma ọ bụ mwepu njem na-aga n'ihu na onye na-eme ihe na-esote, na-ebu otu mkpebi onye na-eme atụmatụ na ngwaọrụ ala, mana nzọụkwụ onye na-eme ihe ahụ na njikọ edozi. A na-eweghachi nzaghachi mbụ na-aga nke ọma n'agbanweghị, gụnyere SSE streaming; ọdịda mgbe iyi na-aga nke ọma malitere enweghị ike ịmegharị ebe a. Ọ bụrụ na ndị niile na-eme ihe (executors) daa, a na-eweghachi ọdịda ikpeazụ. Ịkwụsị onye ahịa na-akwụsị izipu.

```json
{
  "strategy": "pipeline",
  "models": [{ "model": "provider/planner" }, { "model": "provider/executor" }],
  "config": {
    "agenticOrchestration": { "enabled": true, "maxToolRounds": 8 }
  }
}
```

Onye na-eme ihe (executor) nwere ike iwepụta ọtụtụ oku nọọrọ onwe ha n'otu nzaghachi. A na-ejikwa oku ndị dabere na ya na ntụgharị nsonaazụ ngwaọrụ onye ahịa mgbe e mesịrị, na onye na-eme atụmatụ na-enyocha nsonaazụ ọ bụla. `maxToolRounds` na-adabara na `8` ma na-anabata `1`–`32`; ozugbo erutere, onye na-eme atụmatụ ga-ewepụta azịza ikpeazụ kacha mma dị. A na-echekwa mkpebi onye na-eme atụmatụ n'ime, ebe nzaghachi onye ahịa ahọpụtara na-echekwa mmasị iyi mbụ.

### `round-robin` sticky batch na mgbasawanye akaụntụ

Round-robin bụ batched, ọ bụghị otu arịrịọ-kwa-nzọụkwụ:

- `stickyRoundRobinLimit` (combo config, mgbe ahụ `comboStickyRoundRobinLimit`, mgbe ahụ `settings.stickyRoundRobinLimit`, ndabara **3**) na-edobe otu ihe mgbaru ọsọ maka ọtụtụ ihe ịga nke ọma na-esote tupu ịgbanwere. Tọọ combo override na 1 maka ntụgharị otu arịrịọ. Onye nchịkọta combo na-egosi uru dị irè na nke ọkwa ọ si bịa.
- `connectionAwareExpansion` (combo config, mgbe ahụ settings, ndabara **false**) na-agbasawanye nzọụkwụ ọkwa onye na-eweta ọrụ ọ bụla n'ime ihe mgbaru ọsọ kwa akaụntụ tupu ntụgharị. Atụmatụ Group-B (priority, weighted, round-robin, random, p2c, least-used, cost-optimized, lkgp, fill-first, strict-random, context-optimized, cache-optimized, context-relay, fusion, pipeline) na-edobe echiche ọkwa onye na-eweta ọrụ ruo mgbe nke a na-agbanye. Onye nchịkọta combo na-ekpughe inherit / on / off; inherit na-eji ndabara zuru ụwa ọnụ (off).
- Prompt-cache locality routing (`promptCacheAffinityEnabled`, ndabara **true**) na-ahazi njikọ ndị a kọwara (pinned) ka igodo cache dabara adaba nọrọ n'otu akaụntụ. Ọ na-ebute ụzọ karịa round-robin na ntụgharị weighted n'ofe nzọụkwụ kwa akaụntụ a kọwara. Gbanyụọ ya n'okpuru Settings → Combo defaults ma ọ bụrụ na ịchọrọ ntụgharị siri ike. Enweghị override kwa combo.

Maka ntụgharị ọtụtụ akaụntụ n'otu ụdị, họrọ otu nzọụkwụ akaụntụ na-agbanwe agbanwe (connectionId efu, ọdọ mmiri dum) na oke sticky 1, ọ bụghị atọ pinned connectionIds. Nzọụkwụ ndị a kọwara (pinned) gbakwunyere affinity na-ada n'otu akaụntụ ahụ ọbụlagodi mgbe RR counter na-aga n'ihu.

## Atụmatụ Fusion

`fusion` bụ naanị atụmatụ nke **na-adịghị** ahọrọ otu ebumnuche. Ọ na-eziga prompt ahụ
gaa na **ụdị nlereanya panel niile n'otu oge**, mgbe ahụ **ụdị nlereanya ọkaikpe** a pụrụ ịhazi
na-achịkọta otu azịza ikpeazụ site na nzaghachi panel niile. E si na `decolua/9router`
nke upstream bugharịa ya (nhazi Fusion nke OpenRouter); mmejuputa ya dị na `open-sse/services/fusion.ts`.

Otu o si arụ ọrụ:

0. **Ịgafe panel maka arịrịọ nwere ngwaọrụ** — arịrịọ nwere array `tools` na-adịghị efu, nke
   `tool_choice` ya abụghị `"none"` kpọmkwem, na-awụfe panel kpamkpam: a na-ebuga ya ozugbo na
   otu ụdị nlereanya (ọkaikpe ahaziri, ma ọ bụ `panel[0]`), ebe a na-ebufe `tools`/`tool_choice`
   n'enweghị mgbanwe. Ndị otu panel enweghị ohere iji ngwaọrụ, ntuziaka nchịkọta nke ọkaikpe
   na-egbochikwa iwepụta oku ngwaọrụ, ya mere ndị ahịa agentic/ndị na-akpọ ngwaọrụ
   na-enweta ezigbo mkpebi oku ngwaọrụ kama prose a chịkọtara (#6771).
1. **Mgbasa n'akụkụ niile** (naanị maka arịrịọ na-enweghị ngwaọrụ) — a na-eziga prompt ahụ na ụdị
   nlereanya panel niile n'otu oge, na-amanye ha ka ha ghara iji streaming ma wepụ ngwaọrụ
   (ọkaikpe chọrọ prose zuru ezu iji chịkọta azịza).
2. **Nchịkọta quorum-grace** — ozugbo azịza `minPanel` rutere, obere grace
   timer na-amalite maka ndị na-egbu oge, mgbe ahụ fusion na-eji ihe ọ bụla anakọtara gaa n'ihu.
   Nke a na-amachi ntaramahụhụ ụdị nlereanya kacha nwayọọ na-etinye na wall time, site na hard timeout.
3. **Nchịkọta nke ọkaikpe** — a na-ezo aha azịza panel (`Isi Mmalite 1`, `Isi Mmalite 2`, … — ka
   ọkaikpe wee tụọ ọdịnaya, ọ bụghị aha ụdị nlereanya), ma nyefee ha n'aka ọkaikpe, nke na-enyocha
   nkwekọrịta / esemokwu / mkpuchi ezughị ezu / nghọta pụrụ iche / ebe a na-ahụghị anya, ma mesịa
   dee **otu** azịza nwere ikike. Oku ọkaikpe ahụ na-edowe flag `stream` mbụ nke onye ahịa
   yana ngwaọrụ, ka streaming na ojiji ngwaọrụ downstream wee ka na-arụ ọrụ.
4. **Mbelata ọrụ n'enweghị ndakpọ** — azịza panel 0 → `503`; naanị otu nke fọdụrụ → a na-eweghachi
   azịza ahụ ozugbo (ọ dịghị ihe a ga-ejikọta); panel nwere naanị otu ụdị nlereanya na-aza ozugbo.

Onye otu panel nwekwara ike ịbụ nzọụkwụ `combo-ref` (`{kind: "combo-ref", comboName: "..."}`) nke na-arụtụ aka
na combo ọzọ — a na-edozi ya dị ka **otu olu panel black-box** (dispatch recursive zuru ezu banye na
combo ahụ a kpọtụrụ aka, ọ bụghị fan-out nke ebumnuche combo ahụ), yana nchedo depth/cycle
ahụ atụmatụ ndị ọzọ niile na-eji combo-ref na-ejibu (#6764).

### Nhazi

## Ụlọ Ọrụ Virtual Auto-Combo

Injin Auto Combo anaghị achọ ka akọwapụta combo tupu oge eruo. Kama nke ahụ, `open-sse/services/autoCombo/virtualFactory.ts` na-emepụta ndị a ga-atụle ozugbo:

1. Ọ na-ewepụta `getProviderConnections({ isActive: true })` (njikọ niile enyere aka)
2. Ọ na-enyocha ma hapụ naanị ndị nwere credentials ziri ezi (API key ma ọ bụ OAuth token na-agwụbeghị oge site na `hasUsableOAuthToken()`)
3. Ọ na-atụnyere ha na `getProviderRegistry()` maka nnweta model + ọnụahịa
4. Maka tuple ọ bụla `(provider, model, connection)`, ọ na-emepụta `VirtualAutoComboCandidate`
5. Ọ na-ahọrọ `connection.defaultModel` (ma ọ bụ model mbụ dị na registry) dịka ebe a ga-eziga arịrịọ
6. Ọ na-enye candidate ọ bụla akara site na iji `scorePool()` nwere ihe 16 na ngwugwu weight nke variant ahụ
7. Ọ na-eweghachi `AutoComboConfig` nke sitere na ya ma dị na memory maka `handleComboChat()` — anaghị echekwa ya na DB ma ọlị

Nke a pụtara na **ịgbakwunye provider ọhụrụ nke enyere `auto/*` aka na-agbasawanye candidate pool na-akpaghị aka** — ọ dịghị mkpa iji aka dezie combo. A na-ewughachi virtual combo maka arịrịọ ọ bụla, ya mere a na-achọpụta njikọ ọhụrụ agbakwunyere ma ọ bụ ndị laghachiri n'ọnọdụ ahụike ozugbo.

## Mmezi Onwe Ya

- **Mwepụ nwa oge**: Score < 0.2 → ewepụ ya maka nkeji 5 (backoff na-abawanye nwayọ nwayọ, nke kachasị bụ nkeji 30)
- **Ịmara ọnọdụ circuit breaker**: OPEN → ewepụ ya na-akpaghị aka; HALF_OPEN → arịrịọ nnwale
- **Ọnọdụ nsogbu**: >50% OPEN → gbanyụọ exploration, mee ka nkwụsi ike ruo ogo kachasị
- **Nlaghachi mgbe cooldown gasịrị**: Mgbe mwepụ ahụ kwụsịrị, arịrịọ mbụ bụ "probe" nwere timeout ebelatara

## Nnyocha Bandit

A na-eziga 5% nke arịrịọ (enwere ike ịhazi ya) n'aka provider ndị ahọrọghị n'usoro maka exploration. A na-agbanyụ ya n'ọnọdụ nsogbu.

## API

Enweghị **`POST /api/combos/auto` endpoint pụrụ iche** — A na-eji Auto-Combo eme ihe n'ụzọ abụọ:

1. **Zero-config (nke a na-atụ aro):** Ziga arịrịọ mmecha nkata ọ bụla na `model: "auto"` ma ọ bụ `model: "auto/<variant>"`. Ụlọ ọrụ mebere emebe (virtual factory) na-ewu combo ahụ maka arịrịọ ọ bụla — ọ dịghị mkpa nchekwa (persistence), ọ dịghịkwa mkpa oku API.

2. **Combo echekwara (persisted) na `strategy: "auto"`:** Mepụta combo nkịtị site na `POST /api/combos` wee tọọ `strategy: "auto"` gbakwunyere `config.auto.weights` / `config.auto.candidatePool`. A na-eji otu injin akara (scoring engine) ahụ eme ihe; a na-echekwa combo ahụ na `combos` ma nwee ike iji ya mee ihe ọzọ site na ID.

Maka nchọpụta, `GET /api/combos/auto` na-edepụta ụdị ọ bụla (variant) ya na ọdọ ndị na-azọ ọkwa (candidate pool) ya edoziri gbakwunyere `context_length` / `max_output_tokens` — MAX n'ofe windo nke ọdọ ndị na-azọ ọkwa ahụ. Ndị ahịa (dịka opencode plugin) ga-ekwupụta ụkpụrụ ndị a kama `0`: efu (zero) context na-agbanyụ opencode's auto-compaction kpamkpam, na-ekwe ka nnọkọ (sessions) too ruo mgbe nhichapụ akụkọ ihe mere eme nke gateway na-ebibi context. MAX dị mma ịkpọsa n'ihi na auto-combo context pre-filter na-ebugharị arịrịọ ndị buru ibu gaa na ndị na-azọ ọkwa nwere windo buru ibu.

```bash
# Zero-config usage (no combo creation)
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{"model":"auto/coding","messages":[{"role":"user","content":"Hello"}]}'

# Persisted auto combo via the regular combos endpoint
curl -X POST http://localhost:20128/api/combos \
  -H "Content-Type: application/json" \
  -d '{"id":"my-auto","name":"Auto Coder","strategy":"auto","config":{"auto":{"candidatePool":["anthropic","google","openai"],"weights":{"quota":0.15,"health":0.3,"costInv":0.05,"latencyInv":0.35,"taskFit":0.1,"stability":0,"tierPriority":0.05}}}}'
```

### Atụmatụ Auto router

Combo ndị echekwara `strategy: "auto"` nwere ike ịtọ `config.routerStrategy` (ma ọ bụ `config.auto.routerStrategy` ochie) gaa na otu n'ime ndị a:

- `rules` — akara a tụrụ atụ (weighted scoring) ndabara
- `score` — na-ahọrọ akara a tụrụ atụ kachasị elu. Ịha nhata kpọmkwem na-echekwa usoro ndị na-azọ ọkwa ahaziri; `explorationRate` dị ugbu a na-ewere ihe nlele site na ọdọ zuru ezu a haziri ahazi.
- `cost` / `eco` — onye na-eweta ọrụ (provider) dị ọnụ ala ma dị mma
- `latency` / `fast` — latency p95 kachasị ala yana ntaramahụhụ ntụkwasị obi
- `sla-aware` / `sla` — họrọ ndị na-azọ ọkwa na-emezu p95 latency, ọnụego mmejọ, na SLOs ọnụ ahịa nhọrọ
- `lkgp` — onye na-eweta ọrụ kacha mma ikpeazụ a maara (last known good provider) buru ụzọ
- `nadir` — jụọ API mkpebi [Nadir](https://getnadir.com) ụdị ihe nlereanya (model) dị n'ọdọ ahụ nke mkpali (prompt) chọrọ; opt-in, daa-mepee (fail-open) gaa na `rules`

### Atụmatụ Router n'ụzọ zuru ezu

Injin auto-combo na-ekpughe mmejuputa **RouterStrategy** 7 nwere ike itinye (pluggable) nke ị nwere ike ịgbanwe site na `config.routerStrategy` (ma ọ bụ `config.auto.routerStrategy` ochie). Atụmatụ ọ bụla na-ahọrọ otu onye na-eweta ọrụ site na ọdọ ndị na-azọ ọkwa, nyere `RoutingContext` (ụdị ọrụ, ngwaọrụ/ntụnye ọhụụ, atụmatụ token, amụma SLA nhọrọ, onye na-eweta ọrụ kacha mma ikpeazụ a maara).

#### 1. `rules` (ndabara) — akara a tụrụ atụ (weighted scoring) nke ihe 16

Na-ekpuchi injin akara dị ugbu a. Na-enyocha ndị na-azọ ọkwa `OPEN` circuit-breaker, wee na-agba `scorePool()` na ụdị ọrụ dị ugbu a na `getTaskFitness()`, na-ahọrọ onye na-eweta ọrụ nwere akara kachasị elu.

```ts
class RulesStrategyImpl implements RouterStrategy {
  readonly name = "rules";
  readonly description = "16-factor weighted scoring (see DEFAULT_WEIGHTS)";

  select(pool, context) {
    const eligible = pool.filter((c) => c.circuitBreakerState !== "OPEN");
    const ranked = scorePool(
      eligible.length > 0 ? eligible : pool,
      context.taskType,
      undefined,
      getTaskFitness
    );
    return { provider: ranked[0].provider /* ... */ };
  }
}
```

**Mgbe ị ga-eji ya**: Ndabara. Jiri ya mgbe ịchọrọ nguzozi n'ofe akara niile.

**Alias**: `rules` (enweghị alias)

---

#### 2. `cost` / `eco` — onye na-eweta ọrụ dị ọnụ ala ma dị mma

Na-ahazi ọdọ ndị na-azọ ọkwa site na `costPer1MTokens` (n'ịrị elu) ma na-ahọrọ nke kachasị ọnụ ala. Na-enyocha ndị na-azọ ọkwa `OPEN` na mbụ.

```ts
class CostStrategyImpl implements RouterStrategy {
  readonly name = "cost";
  readonly description = "Always selects cheapest available provider";

  select(pool, context) {
    const healthy = pool.filter((c) => c.circuitBreakerState !== "OPEN");
    const sorted = [...healthy].sort((a, b) => a.costPer1MTokens - b.costPer1MTokens);
    return { provider: sorted[0].provider /* ... */ };
  }
}
```

**Mgbe ị ga-eji ya**: Ọrụ ndị nwere mmetụta ọnụ ahịa, nhazi batch, ma ọ bụ ọrụ ndabere.

**Aliases**: `cost`, `eco`

---

#### 3. `latency` / `fast` — latency p95 kachasị ala yana ntaramahụhụ ntụkwasị obi

Na-ahazi site na `p95LatencyMs + (errorRate * 1000)`. Ntaramahụhụ ọnụego mmejọ na-ahụ na ndị na-eweta ọrụ na-adịghị ntụkwasị obi na-enweta ọkwa dị ala ọbụlagodi ma ọ bụrụ na latency ha dị ala.

```ts
class LatencyStrategyImpl implements RouterStrategy {
  readonly name = "latency";
  readonly description = "Prioritizes lowest p95 latency with reliability weighting";

  select(pool, context) {
    const healthy = pool.filter((c) => c.circuitBreakerState !== "OPEN");
    const sorted = [...healthy].sort(
      (a, b) => a.p95LatencyMs + a.errorRate * 1000 - (b.p95LatencyMs + b.errorRate * 1000)
    );
    return { provider: sorted[0].provider /* ... */ };
  }
}
```

**Mgbe ị ga-eji ya**: Ọrụ ndị nwere mmetụta latency dịka nkata oge n'ezie, autocomplete, ma ọ bụ ndị na-enyere aka koodu na-emekọrịta ihe.

**Aliases**: `latency`, `fast`

---

#### 4. `sla-aware` / `sla` — nnabata SLO latency/mmejọ/ọnụ ahịa

Na-enye onye na-azọ ọkwa ọ bụla akara site n'otú o si emezu amụma SLO ahaziri:

| Ihe a na-atụle               | Ibu | Usoro mgbakọ                                           |
| ---------------------------- | --- | ------------------------------------------------------ |
| Akara oge nchere (Latency)   | 35% | `threshold / max(value, ε)`                            |
| Akara njehie (Error)         | 35% | `threshold / max(value, ε)`                            |
| Akara ahụike (Health)        | 15% | `1.0` (CLOSED) / `0.5` (HALF_OPEN) / `0.0` (OPEN)      |
| Akara ọnụ ahịa (Cost)        | 10% | `threshold / max(value, ε)` ma ọ bụ inverse normalized |
| Akara nkwụsi ike (Stability) | 5%  | inverse normalized latency stddev                      |

Mgbe `hardConstraints: true`, a na-ahazi ndị na-azọ ọkwa (candidates) site na **akara mmebi iwu** (otú ha si gafere SLO ọ bụla), wee soro akara nchịkọta. Ma ọ bụghị ya, ọ bụ naanị akara nchịkọta ka a na-eji.

```ts
class SLAStrategyImpl implements RouterStrategy {
  readonly name = "sla-aware";
  readonly description =
    "Selects the provider most likely to satisfy latency, error-rate, and cost SLOs";

  select(pool, context) {
    // ... scores each candidate against policy: { targetP95Ms, maxErrorRate, maxCostPer1MTokens, hardConstraints }
  }
}
```

**Ubi SLA** (nke edobere na nhazi combo):

```json
{
  "strategy": "auto",
  "config": {
    "routerStrategy": "sla-aware",
    "slaTargetP95Ms": 1500,
    "slaMaxErrorRate": 0.05,
    "slaMaxCostPer1MTokens": 5,
    "slaHardConstraints": true
  }
}
```

**Mgbe a ga-eji ya eme ihe**: Ọrụ mmepụta nwere oke oge nchere, ọnụego njehie, ma ọ bụ mmefu ego siri ike.

**Aha ọzọ**: `sla-aware`, `sla`

#### 5. `lkgp` — onye na-eweta ọrụ kacha mma a maara ikpeazụ na mbụ

Na-anwale **onye na-eweta ọrụ kacha mma a maara ikpeazụ** (ọ bụrụ na edobere ya) na mbụ, wee laghachi na atụmatụ `rules`. Ọ bara uru maka njikọ nnọkọ (session stickiness) — otu onye na-eweta ọrụ na-ejikwa arịrịọ ndị na-esote na mkparịta ụka.

```ts
class LKGPStrategyImpl implements RouterStrategy {
  readonly name = "lkgp";
  readonly description = "Tries last known good provider first, then falls back to rules";

  select(pool, context) {
    if (context.lkgpEnabled === false) {
      return getStrategy("rules").select(pool, context);
    }

    if (context.lastKnownGoodProvider) {
      const candidates = pool.filter(
        (c) => c.provider === context.lastKnownGoodProvider && c.circuitBreakerState !== "OPEN"
      );
      if (candidates.length > 0) {
        return { provider: candidates[0].provider /* ... */ };
      }
    }

    // Fallback to rules strategy
    return getStrategy("rules").select(pool, context);
  }
}
```

**Mgbe a ga-eji ya eme ihe**: Mkparịta ụka nwere ọtụtụ ntụgharị ebe ịchọrọ otu onye na-eweta ọrụ ka ọ na-ejikwa arịrịọ ndị na-esote (dịka, maka nchekwa data (caching), nkwado ọnọdụ, ma ọ bụ nkwụsi ike ọnụ ahịa).

**Aha ọzọ**: `lkgp` (enweghị aha ọzọ)

#### 6. `nadir` — nhọrọ ihe nlereanya (model) nke na-amata ihe a na-ajụ (prompt-aware) site na Nadir

Atụmatụ ọ bụla dị n'elu na-ahazi ndị na-azọ ọkwa site na telemetry nke ha; ọ dịghị nke na-agụ arịrịọ ahụ. `nadir` na-eziga ntụgharị onye ọrụ ikpeazụ gbakwunyere ID ihe nlereanya nke pool ahụ na API mkpebi [Nadir](https://getnadir.com) (`POST /v1/bucket`) ma na-ebugharị ya na ihe nlereanya Nadir họọrọ site na menu ahụ (`simple` → ihe nlereanya kacha ọnụ ala nwere ike, `complex` → nke kacha ọhụrụ). Njikọ na-ejere ihe nlereanya ahụ ozi ka na-ahọrọ site na `rules`, yabụ oke (quota), ahụike na ọnụ ahịa na-aga n'ihu na-ekpebi akaụntụ.

```json
{
  "strategy": "auto",
  "config": {
    "routerStrategy": "nadir",
    "nadir": {
      "apiKey": "ndr_...",
      "baseUrl": "https://api.getnadir.com",
      "timeoutMs": 2000
    }
  }
}
```

`OMNIROUTE_NADIR_API_KEY` na `OMNIROUTE_NADIR_BASE_URL` bụ ndabere gburugburu (env fallbacks) maka eriri abụọ ahụ. `baseUrl` dị mkpa naanị maka Nadir nke onwe gị (a na-anabata `/v1` na njedebe). Oku na-enweghị igodo (Keyless calls) na-ada na ọkwa amaghị aha nke Nadir, nke nwere oke ọnụego kwa IP.

Ihe na-apụ na igbe ahụ: ederede ozi onye ọrụ ikpeazụ (mkpụrụedemede 16k mbụ), ID ihe nlereanya ndị na-azọ ọkwa na mkpado ọwa `source: "omniroute"`. Enweghị ihe nkwalite sistemụ (system prompt), akụkọ ihe mere eme, ngwaọrụ ma ọ bụ isi okwu (headers).

Omume ọdịda bụ fail-open: oge nkwụsị (ndabara 2000 ms), non-2xx, onye ọbịa a na-apụghị iru, nzaghachi na-ezighi ezi ma ọ bụ nhọrọ na-abụghị pool ahụ na-edozi na mkpebi `rules` ma a na-etinye `NadirStrategy: fallback (…)` n'ihu ihe kpatara ya. Mgbe oku dara ada, atụmatụ ahụ na-awụfe netwọkụ ahụ maka sekọnd 30, yabụ nkwụsị ọrụ na-efu otu oge nkwụsị kwa sekọnd 30 kama otu kwa arịrịọ. Ihe omume nbudata na-akọ `strategy: "nadir"` naanị mgbe Nadir mere nhọrọ ahụ n'ezie.

**Mgbe a ga-eji ya eme ihe**: okporo ụzọ nwere ọkwa ihe isi ike dị iche iche na pool nke nwere ọkwa ihe nlereanya dị iche iche (obere, ọkara, na nke kacha ọhụrụ), ebe ịchọrọ ibelata ọnụ ahịa nke ịhọrọ ihe nlereanya kacha ọhụrụ mgbe niile.

**Aha ọzọ**: `nadir` (enweghị aha ọzọ)

## Otu tiers si daba na Auto-Combo

Ọrụ ntule nwere ihe 16 (`open-sse/services/autoCombo/scoring.ts`) na-ewere ịbụ onye otu tier dị ka akara abụọ: `tierPriority` (0.0476) na `tierAffinity` (0.0476). Lee [tebụl ihe ntule bụ isi](#how-it-works-persisted-auto-combos) dị n’elu maka nchịkọta `DEFAULT_WEIGHTS` zuru ezu — edepụtara mgbanwe pụrụ iche maka pack ọ bụla (ship-fast/cost-saver/quality-first/
offline-friendly) na tebụl "Profaịlụ ibu maka pack ọ bụla".

Tier naanị ya **anaghị** eme ka Tier 1 buru ụzọ — ọ bụrụ na latency nke Tier 1 adịghị mma ma ọ bụ na ntụnyere ọnụahịa na ogo adịghị mma, Tier 2 ga-emeri. Iji manye usoro tier, jiri atụmatụ combo `priority` ma hazie ndị na-eweta ọrụ dịka tier ha si dị.

Iji nye Tier 1 (ndebanye aha) nnukwu uru, bulie ibu `tierPriority`:

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "tierPriority": 0.3, "costInv": 0.05 } } }
}
```

Lee [`docs/guides/TIERS.md`](../guides/TIERS.md) maka nkọwa tier na nhazi ndị na-eweta ọrụ.
