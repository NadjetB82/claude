## Ìdarí-Ojú-ọ̀nà Aládàáṣe Láìsí Ìṣètò (`auto/` prefix)

> **TUNTUN:** Kò nílò ṣíṣẹ̀dá combo. Lo `auto/` prefix ní tààrà nínú client èyíkéyìí.

### Àwọn Àpẹẹrẹ Kíákíá

| ID Model       | Variant | Ìhùwàsí                                                                      |
| -------------- | ------- | ---------------------------------------------------------------------------- |
| `auto`         | default | Gbogbo provider tí a ti sopọ̀, ọgbọ́n LKGP, àwọn ìwọ̀n tó dọ́gba                 |
| `auto/coding`  | coding  | Àwọn ìwọ̀n tó fi dídára síwájú, ó yẹ fún ṣíṣẹ̀dá code                          |
| `auto/fast`    | fast    | Yíyan pẹ̀lú ìwọ̀n tí latency rẹ̀ kéré                                           |
| `auto/cheap`   | cheap   | Ìdarí-ọ̀nà tí a ṣe àtúnṣe fún iye owó (iye owó tó kéré jù lọ lákọ̀ọ́kọ́)         |
| `auto/offline` | offline | Ó ṣe ojú rere sí àwọn provider tó ní quota tó pọ̀ jù lọ                       |
| `auto/smart`   | smart   | Dídára-lákọ̀ọ́kọ́ + ìwọ̀n ìṣàwárí tó ga jù (10%) fún ìṣàwárí model tó dára sí i  |
| `auto/lkgp`    | lkgp    | LKGP ní tààrà (kannáà bí `auto` default)                                     |
| `auto/chaos`   | chaos   | Ìtànká ní afiwe, model kan fún provider kọ̀ọ̀kan (kì í ṣe fífi àṣìṣe sínú ètò) |

### Àkójọpọ̀ Category × Tier (`auto/<category>:<tier>`)

Àwọn suffix oníṣọ̀nà OpenRouter ya **irú ọ̀nà wo** (category) sọ́tọ̀ kúrò lọ́dọ̀ **bí a ṣe máa mú un péye** (tier), kí o lè ṣàkójọpọ̀ wọn bó ṣe wù ọ́ (#4235 Phase B, `open-sse/services/autoCombo/suffixComposition.ts`):

- **Àwọn Category** (ṣe àlẹ́mọ́ candidate pool nípasẹ̀ agbára): `coding` · `reasoning` · `vision` · `chat` · `multimodal`. `vision`/`multimodal` pa àwọn model tó lágbára vision mọ́; `reasoning` pa àwọn model reasoning/thinking mọ́.
- **Àwọn Tier** (yan àwọn ìwọ̀n ìṣírò / àlẹ́mọ́ pool): `fast` (ship-fast) · `cheap` (alias `floor`, olùfipamọ́ owó) · `reliable` (ìlera circuit-breaker + ìdúróṣinṣin latency) · `free` / `pro` (ṣe àlẹ́mọ́ pool nípasẹ̀ tier model pẹ̀lú `classifyTier` — free-tier sí premium).

| Àpẹẹrẹ                 | Ó yanjú sí                                                        |
| ---------------------- | ----------------------------------------------------------------- |
| `auto/coding:fast`     | pool coding, àwọn ìwọ̀n latency-kékeré                             |
| `auto/coding:cheap`    | pool coding, tí a mú péye fún iye owó (alias `auto/coding:floor`) |
| `auto/reasoning:pro`   | àwọn model reasoning/thinking nìkan, tier premium                 |
| `auto/vision`          | àwọn model tó lágbára vision (kò sí tier → àwọn ìwọ̀n tó dọ́gba)    |
| `auto/multimodal:free` | àwọn model tó lágbára multimodal, tier ọ̀fẹ́ nìkan                  |

`auto/<category>[:<tier>]` tó bá wúlò máa ń yanjú nígbà tí a bá béèrè; àkójọ kékeré tí a ti fara balẹ̀ yàn ni a ń polówó nínú `/v1/models` àti dashboard (`AUTO_SUFFIX_VARIANTS` nínú `open-sse/services/autoCombo/builtinCatalog.ts`). Ṣíṣe àlẹ́mọ́ jẹ́ **fail-open** — bí constraint kan kò bá bá model kankan tí a ti sopọ̀ mu, a máa lo gbogbo pool náà kí ìdarí-ọ̀nà má bàjẹ́ láé. Core scorer (`combo.ts`) kò yí padà; a lo àlẹ́mọ́ category/tier nínú `buildAutoCandidates`.

> **Ìmọ̀ nípa model ní àkókò gidi:** ìbámu ìdarí-ọ̀nà aládàáṣe ń gba ìmọ̀ láti inú àwọn ipò **Arena ELO** ní àkókò gidi + data tier **models.dev** nígbà tí flag `ARENA_ELO_SYNC_ENABLED` bá wà ní títàn (bí bẹ́ẹ̀ kọ́, ó padà sí static fitness map).

**Bí a ṣe ń lò ó:**

```bash
# Any IDE or CLI tool that supports OpenAI format
Base URL: http://localhost:20128/v1
API Key:  <your-endpoint-key>

# In your code/config, set model to:
model: "auto"                 # balanced default
model: "auto/coding"          # best for coding tasks
model: "auto/fast"            # fastest available
model: "auto/cheap"           # cheapest per token
```

**Ohun tó máa ṣẹlẹ̀:**

1. OmniRoute máa ṣàwárí `auto/` prefix nínú `src/sse/handlers/chat.ts`
2. Ó máa béèrè gbogbo **àsopọ̀ provider tó ń ṣiṣẹ́** láti inú database
3. Ó máa ṣe àlẹ́mọ́ sí àwọn tó ní credentials tó wúlò (kọ́kọ́rọ́ API tàbí token OAuth)
4. Ó máa pinnu model fún àsopọ̀ kọ̀ọ̀kan (`connection.defaultModel` tàbí model àkọ́kọ́ ti provider)
5. Ó máa kọ **virtual combo** sínú memory (a kò fi pamọ́ sínú DB)
6. Ó máa darí ojú-ọ̀nà ní lílo profaili ìwọ̀n variant tí a yàn + ọgbọ́n LKGP

**Àwọn àbùdá pàtàkì:**

- ✅ **Ó máa ń ṣiṣẹ́ nígbà gbogbo:** Kò sí toggle, kò sí ṣíṣẹ̀dá combo, kò sì nílò ìṣètò
- ✅ **Dynamic:** Ó máa ń fi àwọn provider tí a sopọ̀ lọ́wọ́lọ́wọ́ hàn ní aládàáṣe
- ✅ **Ìdúróṣinṣin session:** LKGP ń rí i dájú pé provider tó ṣàṣeyọrí kẹ́yìn ni a fún ní ààyò
- ✅ **Ó mọ̀ nípa ọ̀pọ̀ account:** Àsopọ̀ provider kọ̀ọ̀kan di candidate ọ̀tọ̀
- ✅ **Kò sí kíkọ sínú DB:** Virtual combo wà fún request náà nìkan, kò sì ní persistence overhead rárá

### Ìṣàkóso candidate fún kọ́kọ́rọ́ kọ̀ọ̀kan (#7819, Level 1+2)

`GET /v1/auto-combo/{channel}/candidates` (`{channel}` = suffix lẹ́yìn `auto/`, tàbí
`auto` gangan fún channel ìpìlẹ̀) jẹ́ endpoint **kíkà-nìkan** tó ṣe àtòjọ
candidate pool lọ́wọ́lọ́wọ́ ti channel `auto/*`, tí a ṣe lọ́ṣọ̀ọ́ pẹ̀lú ìwọlé ní àkókò gidi, nípa lílo
àwọn kíkà resilience tó ti wà tẹ́lẹ̀ (kì í lo raw breaker `state` láé):

- circuit breaker provider — `getCircuitBreaker(provider).getStatus()` / `.canExecute()`
- cooldown àsopọ̀ — `rateLimitedUntil` / `testStatus` lórí row
  `provider_connections` tí a ti yanjú
- ìdènà model — `isModelLocked(provider, connectionId, model)`

Candidate kọ̀ọ̀kan tún ní flag `excluded` ti kọ́kọ́rọ́ API yìí. Àwọn ohun tí a yọkúrò ni a ń tọ́jú
fún kọ́kọ́rọ́ API kọ̀ọ̀kan (table `auto_candidate_overrides`, migration `128`) — OmniRoute jẹ́
single-tenant tí kò ní table `users`, nítorí náà `apiKeyId` ni identity gidi fún olùpè kọ̀ọ̀kan
tó sún mọ́ ọn jù — a sì ń fi ipa mú un ní candidate-pool chokepoint nínú
`open-sse/services/autoCombo/virtualFactory.ts` nípasẹ̀ `filterExcludedCandidates()` tó jẹ́ pure, tí a sì ti ṣe
unit-test rẹ̀ (`open-sse/services/autoCombo/candidateOverrides.ts`).
Àlẹ́mọ́ náà jẹ́ **fail-open**: apiKeyId/channel tí a kò ṣètò tàbí ìkùnà lookup DB, àwọn méjèèjì
máa fi pool náà sílẹ̀ láìṣe àlẹ́mọ́, nítorí náà operator tí kò ní override kankan tí a ṣètò máa rí ìdarí-ọ̀nà
tó jẹ́ byte-identical sí bí ó ti rí ṣáájú feature yìí.

**A sun sí ọ̀ràn ìtẹ̀lé:** ìwọ̀n olùdíje-kọ̀ọ̀kan + ìṣètò tó ṣe kedere (Ìpele 3
— èyí ń wọ inú àwọn ipa ọgbọ́n ìwọ̀n/ààyò tó wà tẹ́lẹ̀) àti fífi ọgbọ́n
`combo.ts` kan pàtó mọ́ ikanni `auto/*` kọ̀ọ̀kan (Ìpele 4). Wo ètò #7819 fún ìbéèrè
tó ṣì wà lórí bóyá àwọn ìkọlélórí yẹ kí ó dúró gẹ́gẹ́ bí ti kọ́kọ́rọ́-API-kọ̀ọ̀kan tàbí kí ó di ti àgbáyé nítorí
àwòṣe ayálégbé-kan ṣoṣo náà.

**Lẹ́yìn ìpele:**

```txt
Request: { model: "auto/coding" }
   ↓
src/sse/handlers/chat.ts detects prefix
   ↓
createVirtualAutoCombo('coding') → candidatePool from active connections
   ↓
handleComboChat (same engine as persisted combos)
   ↓
Auto-scoring selects best provider/model per request
```

**Àwọn fáìlì ìmúṣẹ:**

| Fáìlì                                                     | Ète                                         |
| --------------------------------------------------------- | ------------------------------------------- |
| `open-sse/services/autoCombo/autoPrefix.ts`               | Olùṣàlàyé ìṣáájú (`parseAutoPrefix`)        |
| `open-sse/services/autoCombo/virtualFactory.ts`           | Ṣẹ̀dá àwọn ohun àfojúrí `AutoComboConfig`    |
| `open-sse/services/autoCombo/providerRegistryAccessor.ts` | Ìkọ́ ìdánwò fún ṣíṣe àfarawé àkọsílẹ̀ olùpèsè |
| `src/sse/handlers/chat.ts`                                | Ìṣọ̀kan: ọ̀nà-kúkúrú ìṣáájú aifọwọ́yí          |
| `src/shared/constants/providers.ts`                       | Àkọsílẹ̀ ètò `SYSTEM_PROVIDERS.auto`         |

## Àwọn Orúkọ Combo Tó Bá Ìdánimọ̀ Àwòṣe Gidi Mu

Combo kan tí `name` rẹ̀ bá ìdánimọ̀ àwòṣe lásán mu pátápátá (fún àpẹẹrẹ, combo tí orúkọ rẹ̀ jẹ́
`gpt-5.5`) jẹ́ **àpẹẹrẹ tí a mọ̀ọ́mọ̀ ṣe tí a sì ṣe àtìlẹ́yìn fún**, kì í ṣe àṣìṣe: ó jẹ́
ọ̀nà fún ìpadà-sí-olùpèsè ní ìpele ìdánimọ̀ àwòṣe gẹ́gẹ́ bí a ti ṣàkọsílẹ̀ rẹ̀ nínú
[#6940](https://github.com/diegosouzapw/OmniRoute/issues/6940). Nítorí pé a máa ń ṣàyẹ̀wò
yíyanju combo ṣáájú yíyanju ìdánimọ̀ àwòṣe lásán
(`getComboForModel()` nínú `src/sse/services/model.ts`), ìbéèrè fún ìdánimọ̀ lásán
`gpt-5.5` ni a máa darí gba àwọn ibi-àfojúsùn combo náà (fún àpẹẹrẹ,
`acme-responses/gpt-5.5`, `backup-responses/gpt-5.5`) dípò fífi ránṣẹ́ tààrà sí
olùpèsè kan ṣoṣo — èyí tún ń lo ààyò combo-ṣáájú-àtúnkọ tí a kọ́ fún
[#3227/#3233](https://github.com/diegosouzapw/OmniRoute/issues/3227), a sì ti dán an wò fún
ìdènà ìpadà-àṣìṣe pẹ̀lú `tests/unit/responses-combo-resolution-3227.test.ts` àti
`tests/unit/combo-name-codex-responses-rewrite.test.ts`.

Ṣíṣẹ̀dá combo tàbí yíyí orúkọ combo padà sí orúkọ tí ó bo ìdánimọ̀ àwòṣe gidi
ni a **kì í kọ̀ láéláé** — ṣíṣe bẹ́ẹ̀ yóò ba ìṣàn iṣẹ́ tí a ti ṣàkọsílẹ̀ yìí jẹ́. Dípò
bẹ́ẹ̀ (#8530), `POST /api/combos` àti `PUT /api/combos/[id]` máa ń fi ààyè
`warning` tí kì í dí iṣẹ́ lọ́wọ́ mọ́ èsì náà nígbà tí orúkọ (tuntun) bá kọlu ìdánimọ̀
àwòṣe gidi kan:

```json
{ "warning": { "code": "COMBO_NAME_SHADOWS_MODEL", "modelId": "gpt-5.5", "providerId": "openai" } }
```

Nígbà ìbẹ̀rẹ̀, `scanComboModelNameCollisionsAtBoot()`
(`src/instrumentation-node.ts`) tún máa ń kọ ìkìlọ̀ `[STARTUP]` ọlọ̀ọ̀kan sí àkọsílẹ̀,
tí ó ṣe àkójọ gbogbo combo tó wà tí ó bo ìdánimọ̀ àwòṣe kan, kí àwọn olùdarí ètò tí
wọ́n bá dojú kọ èyí láìròtẹ́lẹ̀ (dípò mímọ̀ọ́mọ̀ ṣe é, gẹ́gẹ́ bí #6940) lè rí àmì ìkìlọ̀.
Olùrànlọ́wọ́ ìṣàwárí náà wà nínú `src/lib/combos/modelNameCollision.ts`.

## Pípe Combo Àdáni Láti Ọ̀dọ̀ Client Kan

Àwọn combo tí a ti fi pamọ́ (Ètò → Àwọn Combo) ni a máa ń lò nìkan nígbà tí client bá fi **orúkọ gangan** combo náà ránṣẹ́ sínú ààyè `model` — kò sí ìbámu aláìpé tàbí apá kan fún orúkọ combo náà, bẹ́ẹ̀ ni kò sí àfikún `auto/` tó ní í ṣe pẹ̀lú rẹ̀. Ètò yíyanju (`getComboForModel()` nínú `src/sse/services/model.ts`):

1. ìbámu gangan pẹ̀lú orúkọ combo (`model: "my-combo"`),
2. àfikún `combo/<name>` (`model: "combo/my-combo"`),
3. àwọn ìṣàmúlò glob láti àwòṣe sí combo (`/api/model-combo-mappings`).

```bash
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{"model":"my-combo","messages":[{"role":"user","content":"Hello"}]}'
```

Àwọn ìṣòro méjì tí ó wọ́pọ̀:

- **`auto` kì í lo àwọn combo rẹ.** `auto`/`auto/*` máa ń kọ àkójọpọ̀ àwọn olùdíje tirẹ̀ tí kò nílò ìṣètò, ó sì máa ń ṣàyẹ̀wò àwọn combo tí a ti fi pamọ́ nìkan bí combo kan bá jẹ́ orúkọ `auto` ní ti gidi (a kò dámọ̀ràn rẹ̀). Láti darí ìbéèrè gba combo kan, fi orúkọ rẹ̀ gangan ránṣẹ́ — kì í ṣe `auto`.
- **`openrouter/auto` jẹ́ ọjà OpenRouter gidi tí a ń sanwó fún** ("Auto Best Available"), kì í ṣe orúkọ-àpèjúwe OmniRoute. Ó jẹ́ ìforúkọsílẹ̀ àwòṣe adúróṣinṣin kan ṣoṣo nínú ìforúkọsílẹ̀ OpenRouter (`open-sse/config/providers/registry/openrouter/index.ts`), a sì máa ń gba owó rẹ̀ lọ́tọ̀. Lo Ètò → Ìdarí → Fi àwọn àwòṣe tí a ń sanwó fún pamọ́ láti yọ ọ́ kúrò nínú àwọn àkójọpọ̀ `auto`.

Wo [#7992](https://github.com/diegosouzapw/OmniRoute/issues/7992) àti [#7111](https://github.com/diegosouzapw/OmniRoute/issues/7111) fún ìdàrúdàpọ̀ àkọ́kọ́ tí àkọsílẹ̀ yìí ń ṣàlàyé.

## Bí Ó Ṣe Ń Ṣiṣẹ́ (Àwọn Auto-Combo tí a Fi Pamọ́)

Ẹnjini Auto-Combo ń yan olùpèsè/àwoṣe tó dára jùlọ fún ìbéèrè kọ̀ọ̀kan nípasẹ̀ **iṣẹ́ àmì-ìwọ̀n oní-kókó 16** (tí a ṣàlàyé nínú `open-sse/services/autoCombo/scoring.ts` → `DEFAULT_WEIGHTS`). Àpapọ̀ àwọn ìwọ̀n àkọ́kọ́ jẹ́ `1.0`; àwọn ìwọ̀n àṣà ni a tún ṣe àtúnṣe ìwọ̀n wọn nípasẹ̀ `normalizeScoringWeights()`. Méjì nínú mẹ́rìndínlógún náà — `cacheAffinity` àti `resetWindowAffinity` — ní ìwọ̀n àkọ́kọ́ tí ó jẹ́ `0`; `reliability` ní `0` nínú `DEFAULT_WEIGHTS` ṣùgbọ́n ó ní `0.03` nínú àwọn generic pack àti `0.04` nínú `reliability-first`, bẹ́ẹ̀ sì ni `quality` ní `0.02` nínú àwọn pack (`0.03` nínú `quality-first`): wọ́n ṣì ń ṣe ìṣirò wọn fún olùdíje kọ̀ọ̀kan, àti pé `cacheAffinity` ń ṣàkóso yíyọ àwọn ẹ̀dà prompt-cache kúrò lẹ́yìn àmì-ìwọ̀n, nítorí náà àwọn kókó tí ìwọ̀n àkọ́kọ́ wọn jẹ́ odo kò ní kò dìbò nípa àkọ́kọ́ nígbà tí àwọn pack ń ṣe bẹ́ẹ̀.

### `weighted` semantics

`weighted` jẹ́ **àyànfẹ́ àròsọ tí ó dọ́gba fún ìbéèrè kọ̀ọ̀kan**
(`open-sse/services/combo/targetSorters.ts` → `selectWeightedTarget`), kì í ṣe ẹ̀rọ ìdọ́gba:

- Ìbéèrè kọ̀ọ̀kan fa **ìgbésẹ̀ kan** pẹ̀lú ìṣeéṣe `weight / totalWeight`; àwọn ìgbésẹ̀ tí ó ṣẹ́ kù ni a tò ní ìtòlẹ́sẹẹsẹ láti èyí tí ó tóbi jù lọ gẹ́gẹ́ bí ẹ̀wọ̀n ìpadàsẹ́yìn fún ìbéèrè yẹn.
- Ìgbésẹ̀ kan tí ìwọ̀n rẹ̀ jẹ́ `0` (tàbí tí ó kù) **kò ní fa láé** nígbà tí ìgbésẹ̀ mìíràn bá ní ìwọ̀n > 0 — ó lè ṣiṣẹ́ gẹ́gẹ́ bí ìpadàsẹ́yìn lẹ́yìn tí ìgbésẹ̀ tí a fa bá kùnà. Nígbà tí **gbogbo** ìwọ̀n bá jẹ́ 0 nìkan ni àyànfẹ́ yóò di èyí tí ó dọ́gba.
- Àwọn ìgbésẹ̀ tí àwọn ibi-afẹ́ wọn kò wà nílẹ̀ — provider circuit breaker `OPEN`, connection cooldown, model lockout — ni a yọ kúrò nínú àyànfẹ́ kí ó tó ṣẹlẹ̀
  (`open-sse/services/combo/targetResolution.ts`), nítorí náà ìgbésẹ̀ kan tí ó wà ní ipò dáadáa lè ṣẹ́gun gbogbo ìbéèrè fún ìgbà díẹ̀.
- `stickyWeightedLimit` (ìtòlẹ́sẹẹsẹ combo, àìyẹsẹ̀ `1` = kò ṣiṣẹ́) so ìgbésẹ̀ tí a fa mọ́ fún iye àwọn àṣeyọrí tí ó tẹ̀lé ara wọn kí a tó tún fa.

Fún yíyípadà tó múná dógba (strict rotation), lo `round-robin`; àwọn ìwọ̀n tó dọ́gba lórí `weighted` máa ń fúnni ní ìwọ̀n ìṣirò — kì í ṣe ìwọ̀n tó múná dógba — láti ṣàtúnṣe.

### Ìpò pípáìpù (pipeline) ti àṣojú (agentic)

Àkójọ `pipeline` tó ní ó kéré tán àwọn àwòṣe méjì lè yan láti wọ inú ìdarí (routing) ètò/aláṣẹ (planner/executor) pẹ̀lú `config.agenticOrchestration.enabled`. Àfojúsùn àkọ́kọ́ ni ó ń ṣàkóso ètò àti àwọn ìdáhùn ìkẹyìn; àfojúsùn kejì ni ó ń gbé àwọn ìpè irinṣẹ́ (tool calls) tó wà nínú oníbàárà jáde. OmniRoute máa ń wá àwọn ìtẹ̀síwájú ìyọrísí irinṣẹ́ (tool-result continuations) láti inú ìlànà ìbéèrè, ó máa ń bi ètò náà bóyá ìyípadà irinṣẹ́ mìíràn pọn dandan, ó sì máa ń sọ ètò tàbí aláṣẹ di ìgbésẹ̀ ìkẹyìn tó kọjú sí oníbàárà ní ọ̀nà tó yára yí padà.

`config.agenticOrchestration.contextCompaction` tó jẹ́ àṣàyàn máa ń lo ìṣúná ìwọ̀n (payload budget) ọ̀tọ̀ọ̀tọ̀ ṣáájú ìránṣẹ́ ètò tàbí aláṣẹ kọ̀ọ̀kan. Mú un ṣiṣẹ́ ní gbangba:

```json
{
  "enabled": true,
  "defaultMaxChars": 400000,
  "targetRatio": 0.72,
  "toolResultMaxChars": 24000,
  "modelMaxChars": { "provider/planner": 175000, "provider/executor": 300000 }
}
```

Àwọn wọ̀nyí jẹ́ ìṣúná ìwọ̀n lẹ́tà JSON tí ó tẹ̀ léra tí oníṣẹ́ náà yàn, kì í ṣe àwọn fèrèsé àyíká ọ̀rọ̀ (token context windows) tàbí àwọn ààlà òkè tí ó dájú. Àwọn ID àwòṣe tó péye máa ń borí àìyẹsẹ̀ (default). Ní àkọjá ààlà náà, ìkójọpọ̀ (compaction) máa ń yọ àwọn ìtumọ̀ irinṣẹ́ tó jọra, ó máa ń gé ẹ̀rí irinṣẹ́ tó tóbi jù pẹ̀lú àkópọ̀ (digest), ó sì máa ń yọ àwọn ẹgbẹ́ ìtàn tó ti parí kúrò láti dé ìwọ̀n àfojúsùn náà. Ó máa ń pa àwọn ìtọ́ni ètò/oníṣẹ́ mọ́, ìbéèrè oníbàárà tó kẹ́yìn, ìyípadà irinṣẹ́ tó kẹ́yìn pẹ̀lú àwọn ìpè/ìyọrísí tó jọ ṣẹlẹ̀, àti ìtọ́ni ìdarí Gemini tó ṣáájú. Àwọn ìtọ́ni tó wà lókè àti àwọn ètò irinṣẹ́ ni a óò pa mọ́. Àmì ìyọkúrò (omission marker) máa ń gba ìtàn tí a yọ kúrò sílẹ̀; èyí jẹ́ gígé tó dájú, kì í ṣe àkópọ̀ ìtumọ̀. Bí àyíká ọ̀rọ̀ tí a kàn mọ́lẹ̀ bá ṣì kọjá ìṣúná náà, ìbéèrè náà máa ń padà pẹ̀lú 413 ṣáájú kí ó tó kan àwòṣe náà. Pẹ̀lú ìkójọpọ̀ tí a ti mú kúrò tàbí tí ó wà ní ìsàlẹ̀ ààlà náà, ìbéèrè náà kọjá lọ láìyí padà.

Àwọn àwòṣe àfikún lẹ́yìn àfojúsùn kejì ni àwọn aláṣẹ àfẹ́yìn-tì (executor backups) tí a tò lẹ́sẹẹsẹ. Ìdáhùn HTTP tí ó kùnà tàbí àìṣedédé ìrìn-àjò (transport exception) máa ń tẹ̀ síwájú sí aláṣẹ tó kàn, ó ń gbé ìpinnu ètò kan náà àti àwọn irinṣẹ́ abínibí ṣùgbọ́n pẹ̀lú ìtọ́ni ìgbésẹ̀ ti aláṣẹ yẹn àti ìsopọ̀ tí a yanjú. Ìdáhùn àṣeyọrí àkọ́kọ́ ni a óò padà pẹ̀lú láìyí padà, pẹ̀lú SSE streaming; àwọn ìkùnà lẹ́yìn tí ìṣàn (stream) àṣeyọrí bá bẹ̀rẹ̀ kò lè tún wáyé níhìn-ín. Bí gbogbo àwọn aláṣẹ bá kùnà, ìkùnà tó kẹ́yìn ni a óò padà pẹ̀lú. Àwọn ìfagilé oníbàárà (client aborts) máa ń dá ìránṣẹ́ dúró.

```json
{
  "strategy": "pipeline",
  "models": [{ "model": "provider/planner" }, { "model": "provider/executor" }],
  "config": {
    "agenticOrchestration": { "enabled": true, "maxToolRounds": 8 }
  }
}
```

Aláṣẹ náà lè gbé ọ̀pọ̀lọpọ̀ ìpè tó dá dúró jáde nínú ìdáhùn kan. Àwọn ìpè tó sinmi lórí ara wọn ni a máa ń ṣàtúnṣe nínú àwọn ìyípadà ìyọrísí irinṣẹ́ oníbàárà tó kàn, pẹ̀lú ètò náà tó ń ṣàyẹ̀wò gbogbo ìyọrísí. `maxToolRounds` máa ń wà ní `8` gẹ́gẹ́ bí àìyẹsẹ̀, ó sì gba `1`–`32`; nígbà tí ó bá dé ibẹ̀, ètò náà gbọ́dọ̀ gbé ìdáhùn ìkẹyìn tó dára jù lọ jáde. Àwọn ìpinnu ètò inú ni a máa ń kó jọ (buffered), nígbà tí ìdáhùn tó kọjú sí oníbàárà tí a yàn máa ń pa ààyò ìṣàn (streaming preference) àtìbẹ̀rẹ̀pẹ̀pẹ̀ mọ́.

### `round-robin` sticky batch àti ìgbòòrò àkántì (account expansion)

Round-robin jẹ́ èyí tí a kó jọ (batched), kì í ṣe ìbéèrè-kan-fún-ìgbésẹ̀-kọ̀ọ̀kan:

- `stickyRoundRobinLimit` (ìtòlẹ́sẹẹsẹ àkójọ, lẹ́yìn náà `comboStickyRoundRobinLimit`, lẹ́yìn náà `settings.stickyRoundRobinLimit`, àìyẹsẹ̀ **3**) máa ń pa àfojúsùn kan náà mọ́ fún iye àwọn àṣeyọrí tẹ̀lé-ara-wọn bẹ́ẹ̀ ṣáájú kí ó tó yí padà. Ṣètò àkójọ àṣẹ-borí (combo override) sí `1` fún yíyípadà ìbéèrè-kan. Olóòtú àkójọ (combo editor) máa ń fi iye tó wúlò hàn àti ìpele tí ó ti wá.
- `connectionAwareExpansion` (ìtòlẹ́sẹẹsẹ àkójọ, lẹ́yìn náà settings, àìyẹsẹ̀ **false**) máa ń gbalẹ̀ ìgbésẹ̀ ìpele-olùpèsè kọ̀ọ̀kan sí àwọn àfojúsùn fún-àkántì-kọ̀ọ̀kan ṣáájú yíyípadà. Àwọn ọ̀nà Group-B (priority, weighted, round-robin, random, p2c, least-used, cost-optimized, lkgp, fill-first, strict-random, context-optimized, cache-optimized, context-relay, fusion, pipeline) máa ń pa ìwòran ìpele-olùpèsè mọ́ títí tí èyí yóò fi wà ní ipò ṣíṣe. Olóòtú àkójọ máa ń fi inherit / on / off hàn; inherit máa ń lo àìyẹsẹ̀ àgbáyé (off).
- Ìdarí agbègbè ìpamọ́-ìtọ́ni (Prompt-cache locality routing) (`promptCacheAffinityEnabled`, àìyẹsẹ̀ **true**) máa ń tún àwọn ìsopọ̀ tí a kàn mọ́lẹ̀ tò lẹ́sẹẹsẹ kí àwọn bọ́tìnì ìpamọ́ (cache keys) tó bá bára mu lè wà lórí àkántì kan. Ó máa ń gba ipò iwájú lórí yíyípadà round-robin àti weighted kọjá àwọn ìgbésẹ̀ fún-àkántì-kọ̀ọ̀kan tí a kàn mọ́lẹ̀. Mú un kúrò lábẹ́ Settings → Combo defaults bí o bá nílò yíyípadà tó múná dógba. Kò sí àṣẹ-borí fún-àkójọ-kọ̀ọ̀kan.

Fún yíyípadà àkántì-púpọ̀ lórí àwòṣe kan, fẹ́ràn **ìgbésẹ̀ àkántì-tó-ń-yí-padà kan** (empty `connectionId`, gbogbo adágún) pẹ̀lú ìwọ̀n sticky `1`, kì í ṣe àwọn `connectionId` mẹ́ta tí a kàn mọ́lẹ̀. Àwọn ìgbésẹ̀ tí a kàn mọ́lẹ̀ pẹ̀lú ìbáṣepọ̀ (affinity) máa ń wó lulẹ̀ lórí àkántì kan náà kódà nígbà tí ìkàǹtẹ́ RR bá ń tẹ̀ síwájú.

## Ìlànà Fusion

`fusion` ni ìlànà kan ṣoṣo tí **kì í** yan ibi-afẹ́ kan ṣoṣo. Ó máa ń fi ìbéèrè náà
ránṣẹ́ sí **gbogbo awoṣe inú pánẹ́ẹ̀lì ní ìgbà kan náà**, lẹ́yìn náà **awoṣe adájọ́** tí a lè ṣètò yóò ṣàkójọpọ̀
ìdáhùn ìkẹyìn kan ṣoṣo láti inú gbogbo àwọn ìdáhùn pánẹ́ẹ̀lì. A gbé e wá láti `decolua/9router`
ti upstream (àpẹrẹ Fusion ti OpenRouter); ìmúlò rẹ̀ wà nínú `open-sse/services/fusion.ts`.

Bí ó ṣe ń ṣiṣẹ́:

0. **Yíyàgò fún ẹ̀ka irinṣẹ́** — ìbéèrè tí ó ní àkójọpọ̀ `tools` tí kò ṣófo pẹ̀lú
   `tool_choice` tí a kò ṣètò ní pàtó sí `"none"` máa ń fò pánẹ́ẹ̀lì náà kọjá: a máa darí rẹ̀ tààrà sí
   awoṣe kan ṣoṣo (adájọ́ tí a ṣètò, tàbí `panel[0]`) pẹ̀lú `tools`/`tool_choice`
   tí a fi ránṣẹ́ láìyípadà. Àwọn ọmọ ẹgbẹ́ pánẹ́ẹ̀lì kò ní ààyè sí irinṣẹ́, ìtọ́nisọ́nà
   àkójọpọ̀ ti adájọ́ sì ń dín ìmújáde ìpè-irinṣẹ́ kù, nítorí náà àwọn oníbàárà
   agentic/tó ń pe irinṣẹ́ máa ń gba ìpinnu ìpè-irinṣẹ́ gidi dípò ọ̀rọ̀ tí a ṣàkójọpọ̀ (#6771).
1. **Pínkiri** (fún àwọn ìbéèrè tí kò ní irinṣẹ́ nìkan) — a máa fi ìbéèrè náà ránṣẹ́ sí gbogbo awoṣe
   inú pánẹ́ẹ̀lì lẹ́ẹ̀kan náà, a sì fipá mú un láti má ṣe ṣiṣàn, pẹ̀lú yíyọ àwọn irinṣẹ́ kúrò (adájọ́ nílò
   ọ̀rọ̀ pípé láti ṣe àkójọpọ̀).
2. **Ìkójọpọ̀ quorum-grace** — ní kété tí àwọn ìdáhùn `minPanel` bá dé, aago àkókò
   àfikún kúkúrú máa bẹ̀rẹ̀ fún àwọn tó ń pẹ́, lẹ́yìn náà fusion yóò tẹ̀síwájú pẹ̀lú ohunkóhun tí a ti kó jọ.
   Èyí fi òpin sí ìjìyà tí awoṣe tó lọ́ra jù ń fa lórí àkókò gidi, lábẹ́ òpin àkókò líle kan.
3. **Àkójọpọ̀ adájọ́** — a máa yọ ìdánimọ̀ kúrò lára àwọn ìdáhùn pánẹ́ẹ̀lì (`Source 1`, `Source 2`, … — kí
   adájọ́ lè gbé kókó ọ̀rọ̀ wọ̀n, kì í ṣe orúkọ ìṣòwò awoṣe), a ó sì fi wọ́n fún adájọ́, tí yóò ṣe àyẹ̀wò
   ìfohùnṣọ̀kan / àwọn ìtakora / ìbojúmu apá kan / àwọn ìmọ̀ aláìlẹ́gbẹ́ / àwọn ibi tí a kò rí, lẹ́yìn náà
   yóò kọ **ìdáhùn kan ṣoṣo** tó ṣe àṣẹ. Ìpè adájọ́ máa ń pa àsíá `stream` atilẹba
   ti oníbàárà mọ́ pẹ̀lú àwọn irinṣẹ́, kí ṣiṣàn àti lílo irinṣẹ́ ní ìpele tó tẹ̀lé lè máa ṣiṣẹ́.
4. **Ìdínkù iṣẹ́ lọ́nà pẹ̀lẹ́** — ìdáhùn pánẹ́ẹ̀lì 0 → `503`; olùyọ kan ṣoṣo → a máa dá
   ìdáhùn yẹn padà tààrà (kò sí ohun tí a lè ṣàkójọpọ̀); pánẹ́ẹ̀lì awoṣe-kan máa ń dáhùn tààrà.

Ọmọ ẹgbẹ́ pánẹ́ẹ̀lì tún lè jẹ́ ìgbésẹ̀ `combo-ref` (`{kind: "combo-ref", comboName: "..."}`) tó ń tọ́ka sí
combo mìíràn — a máa yanju rẹ̀ gẹ́gẹ́ bí **ohùn pánẹ́ẹ̀lì black-box kan ṣoṣo** (ìdarí recursive pípé sínú
combo tí a tọ́ka sí, kì í ṣe pínkiri sí àwọn ibi-afẹ́ inú combo náà), pẹ̀lú ààbò ìjìnlẹ̀/ìyíká kan náà
tí gbogbo ìlànà mìíràn tó ń lo combo-ref ti ń lò tẹ́lẹ̀ (#6764).

### Ìṣètò

A máa ṣètò rẹ̀ lórí blob `config` ti combo náà (kò nílò ìṣípò schema — ó tún ń lo tábìlì
`combos` tó wà tẹ́lẹ̀):

| Pápá                                     | Irú      | Àìròtẹ́lẹ̀            | Ète                                                                                        |
| :--------------------------------------- | :------- | :------------------ | :----------------------------------------------------------------------------------------- |
| `config.judgeModel`                      | `string` | awoṣe pánẹ́ẹ̀lì àkọ́kọ́ | Awoṣe tó ń ṣàkójọpọ̀ ìdáhùn ìkẹyìn                                                          |
| `config.fusionTuning.minPanel`           | `number` | `2`                 | Àwọn ìdáhùn àṣeyọrí tí a nílò kí aago àkókò àfikún tó bẹ̀rẹ̀ (a fi òpin sí `[2, panelSize]`) |
| `config.fusionTuning.stragglerGraceMs`   | `number` | `8000`              | Bí a ṣe máa dúró pẹ́ tó fún àwọn tó ń pẹ́ lẹ́yìn tí quorum bá pé                              |
| `config.fusionTuning.panelHardTimeoutMs` | `number` | `90000`             | Òpin gédégbé kí awoṣe kan tó dì má bàa dá ìbéèrè náà dúró                                  |

Àwọn iye àìròtẹ́lẹ̀ wà nínú `FUSION_DEFAULTS` (`open-sse/services/fusion.ts`).

## Ilé-iṣẹ́ Auto-Combo Foju

Ẹ́ńjìnnì Auto Combo kò nílò àwọn combo tí a ti ṣàlàyé tẹ́lẹ̀. Dípò bẹ́ẹ̀, `open-sse/services/autoCombo/virtualFactory.ts` ń kọ́ àwọn olùdíje sílẹ̀ lẹ́sẹ̀kẹsẹ̀:

1. Ó gba `getProviderConnections({ isActive: true })` (gbogbo àwọn àsopọ̀ tí a ti mú ṣiṣẹ́)
2. Ó yọ àwọn tí kò ní ẹ̀rí ìdánimọ̀ tó wúlò kúrò (kọ́kọ́rọ́ API tàbí àmì OAuth tí kò tíì parí nípasẹ̀ `hasUsableOAuthToken()`)
3. Ó ṣe àfiwé pẹ̀lú `getProviderRegistry()` fún wíwà awoṣe àti ìdíyelé
4. Fún tuple kọ̀ọ̀kan `(provider, model, connection)`, ó kọ `VirtualAutoComboCandidate`
5. Ó yan `connection.defaultModel` (tàbí awoṣe àkọ́kọ́ nínú registry) gẹ́gẹ́ bí ibi àfojúsùn ìfiránṣẹ́
6. Ó fún olùdíje kọ̀ọ̀kan ní àmì nípa lílo `scorePool()` onífókítà 16 àti àkójọpọ̀ ìwọ̀n ti variant náà
7. Ó dá `AutoComboConfig` inú ìrántí tí ó yọrí sí padà fún `handleComboChat()` — a kò fi pamọ́ sínú DB láéláé

Èyí túmọ̀ sí pé **fífi provider tuntun kan tí a ti mú `auto/*` ṣiṣẹ́ fún kún un yóò mú kí àkójọpọ̀ olùdíje gbòòrò sí i láìfọwọ́sí** — kò nílò àtúnṣe combo pẹ̀lú ọwọ́. A tún combo foju náà kọ́ fún ìbéèrè kọ̀ọ̀kan, nítorí náà àwọn àsopọ̀ tí a ṣẹ̀ṣẹ̀ fi kún un tàbí tí wọ́n ṣẹ̀ṣẹ̀ padà sí ipò ìlera ni a máa ń rí lẹ́sẹ̀kẹsẹ̀.

## Ìwòsàn Ara-ẹni

- **Ìyọkúrò fún ìgbà díẹ̀**: Àmì < 0.2 → yọ ọ́ kúrò fún ìṣẹ́jú 5 (ìfàsẹ́yìn tó ń pọ̀ sí i, ó pọ̀ jù ní ìṣẹ́jú 30)
- **Ìmọ̀ nípa circuit breaker**: OPEN → yọ ọ́ kúrò láìfọwọ́sí; HALF_OPEN → àwọn ìbéèrè àyẹ̀wò
- **Ìpo ìṣẹ̀lẹ̀ pàjáwìrì**: >50% OPEN → pa ìṣàwárí, mú ìdúróṣinṣin pọ̀ sí òpin
- **Ìpadàbọ̀ cooldown**: Lẹ́yìn ìyọkúrò, ìbéèrè àkọ́kọ́ jẹ́ “àyẹ̀wò” pẹ̀lú timeout tí a dín kù

## Ìṣàwárí Bandit

5% àwọn ìbéèrè (tí a lè ṣètò) ni a máa darí sí àwọn provider láìròtẹ́lẹ̀ fún ìṣàwárí. A máa pa á ní ìpo ìṣẹ̀lẹ̀ pàjáwìrì.

## API

Kò sí **endpoint `POST /api/combos/auto` tí ó jẹ́ àkànṣe** — Auto-Combo ni a ń lò ní ọ̀nà méjì:

1. **Zero-config (a ṣedúró rẹ̀):** Ránṣẹ́ ìbéèrè chat completion èyíkéyìí pẹ̀lú `model: "auto"` tàbí `model: "auto/<variant>"`. Virtual factory ń kọ́ combo náà fún ìbéèrè kọ̀ọ̀kan — kò sí ìpamọ́ (persistence), kò sì sí àwọn ìpè API tí ó pọn dandan.

2. **Combo tí ó wà ní ìpamọ́ (persisted) pẹ̀lú `strategy: "auto"`:** Ṣẹ̀dá combo déédéé nípasẹ̀ `POST /api/combos` kí o sì ṣètò `strategy: "auto"` pẹ̀lú `config.auto.weights` / `config.auto.candidatePool`. Ẹ̀rọ ìṣirò (scoring engine) kan náà ni a ń lò; a máa ń pa combo náà mọ́ sínú `combos` ó sì ṣeé lò padà nípasẹ̀ ID.

Fún ìwádìí, `GET /api/combos/auto` ń tò gbogbo variant pẹ̀lú candidate pool tí ó ti yanjú rẹ̀ pẹ̀lú `context_length` / `max_output_tokens` — èyí tí ó jẹ́ MAX láàárín àwọn window ti candidate pool. Àwọn oníbàárà (fún àpẹẹrẹ, opencode plugin) gbọ́dọ̀ polówó àwọn iye wọ̀nyí dípò `0`: context tí ó jẹ́ zero yóò mú kí auto-compaction ti opencode dáwọ́ dúró pátápátá, èyí tí yóò jẹ́ kí àwọn session dàgbà títí tí ìparẹ́ ìtàn (history purge) ti gateway yóò fi pa context run. MAX jẹ́ ohun tí ó wà ní ààbò láti polówó nítorí pé auto-combo context pre-filter ń darí àwọn ìbéèrè tí ó tóbi jù lọ sí àwọn candidate tí ó ní window ńlá.

```bash
# Zero-config usage (no combo creation)
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{"model":"auto/coding","messages":[{"role":"user","content":"Hello"}]}'

# Persisted auto combo via the regular combos endpoint
curl -X POST http://localhost:20128/api/combos \
  -H "Content-Type: application/json" \
  -d '{"id":"my-auto","name":"Auto Coder","strategy":"auto","config":{"auto":{"candidatePool":["anthropic","google","openai"],"weights":{"quota":0.15,"health":0.3,"costInv":0.05,"latencyInv":0.35,"taskFit":0.1,"stability":0,"tierPriority":0.05}}}}'
```

### Àwọn ìlànà olùdarí (Router strategies)

Àwọn combo `strategy: "auto"` tí ó wà ní ìpamọ́ lè ṣètò `config.routerStrategy` (tàbí `config.auto.routerStrategy` ti àtijọ́) sí ọ̀kan nínú àwọn wọ̀nyí:

- `rules` — ìṣirò pẹ̀lú ìwọ̀n (weighted scoring) tí ó jẹ́ àìyẹsẹ̀ (default)
- `score` — ó ń yan ìṣirò pẹ̀lú ìwọ̀n tí ó ga jù lọ tí a ti ṣètò. Àwọn ties tí ó péye ń pa ìtòlẹ́sẹẹsẹ candidate tí a ti ṣètò mọ́; `explorationRate` tí ó wà tẹ́lẹ̀ ń ṣe àyẹ̀wò láti inú gbogbo adágún tí a ti tò lẹ́sẹẹsẹ.
- `cost` / `eco` — olùpèsè tí ó wà ní ìlera tí ó sì jẹ́ ẹni tí ó din owó kù jù lọ
- `latency` / `fast` — p95 latency tí ó kéré jù lọ pẹ̀lú ìjìyà fún àìní ìgbẹ́kẹ̀lé
- `sla-aware` / `sla` — fẹ́ràn àwọn candidate tí ó tẹ́lọ́rùn pẹ̀lú p95 latency, error-rate, àti àwọn SLO owó tí ó jẹ́ àṣàyàn
- `lkgp` — olùpèsè tí ó kẹ́yìn tí a mọ̀ pé ó dára ni ó yẹ kí ó kọ́kọ́ wà
- `nadir` — béèrè lọ́wọ́ API ìpinnu [Nadir](https://getnadir.com) pé irú model wo nínú adágún náà ni prompt náà nílò; opt-in, fail-open sí `rules`

### Àwọn ìlànà olùdarí (Router strategies) ní kíkún

Ẹ̀rọ auto-combo ń ṣí 7 pluggable **RouterStrategy** implementations tí o lè yí padà nípasẹ̀ `config.routerStrategy` (tàbí `config.auto.routerStrategy` ti àtijọ́). Ìlànà kọ̀ọ̀kan ń yan olùpèsè kan láti inú adágún candidate, nígbà tí a bá fún ní `RoutingContext` (irú iṣẹ́, àwọn àmìràn irinṣẹ́/ìríran, ìṣirò token, ìlànà SLA tí ó jẹ́ àṣàyàn, olùpèsè tí ó kẹ́yìn tí a mọ̀ pé ó dára tí ó jẹ́ àṣàyàn).

#### 1. `rules` (default) — 16-factor weighted scoring

Ó ń fi ìwé bo ẹ̀rọ ìṣirò tí ó wà tẹ́lẹ̀. Ó ń yọ àwọn candidate `OPEN` circuit-breaker kúrò, lẹ́yìn náà ó ń ṣiṣẹ́ `scorePool()` pẹ̀lú irú iṣẹ́ lọ́wọ́lọ́wọ́ àti `getTaskFitness()`, ó sì ń yan olùpèsè tí ó ní ìṣirò tí ó ga jù lọ.

```ts
class RulesStrategyImpl implements RouterStrategy {
  readonly name = "rules";
  readonly description = "16-factor weighted scoring (see DEFAULT_WEIGHTS)";

  select(pool, context) {
    const eligible = pool.filter((c) => c.circuitBreakerState !== "OPEN");
    const ranked = scorePool(
      eligible.length > 0 ? eligible : pool,
      context.taskType,
      undefined,
      getTaskFitness
    );
    return { provider: ranked[0].provider /* ... */ };
  }
}
```

**Ìgbà tí ó yẹ kí o lò ó**: Àìyẹsẹ̀ (Default). Lò ó nígbà tí o bá fẹ́ ìwọ̀ntúnwọ̀nsì láàárín gbogbo àwọn àmì.

**Alias**: `rules` (kò sí alias)

---

#### 2. `cost` / `eco` — cheapest healthy provider

Ó ń to adágún candidate lẹ́sẹẹsẹ nípasẹ̀ `costPer1MTokens` (tí ó ń gòkè) ó sì ń yan èyí tí ó din owó kù jù lọ. Ó ń yọ àwọn candidate `OPEN` kúrò ní àkọ́kọ́.

```ts
class CostStrategyImpl implements RouterStrategy {
  readonly name = "cost";
  readonly description = "Always selects cheapest available provider";

  select(pool, context) {
    const healthy = pool.filter((c) => c.circuitBreakerState !== "OPEN");
    const sorted = [...healthy].sort((a, b) => a.costPer1MTokens - b.costPer1MTokens);
    return { provider: sorted[0].provider /* ... */ };
  }
}
```

**Ìgbà tí ó yẹ kí o lò ó**: Àwọn iṣẹ́ tí owó ṣe pàtàkì fún, ṣíṣe iṣẹ́ ní àkópọ̀ (batch processing), tàbí àwọn iṣẹ́ abẹ́lẹ̀ (background jobs).

**Aliases**: `cost`, `eco`

---

#### 3. `latency` / `fast` — lowest p95 latency with reliability penalty

Ó ń to lẹ́sẹẹsẹ nípasẹ̀ `p95LatencyMs + (errorRate * 1000)`. Ìjìyà error-rate ń rí i dájú pé àwọn olùpèsè tí kò ṣe é gbẹ́kẹ̀lé ni a tò sí ìsàlẹ̀ kódà bí latency wọn bá kéré.

```ts
class LatencyStrategyImpl implements RouterStrategy {
  readonly name = "latency";
  readonly description = "Prioritizes lowest p95 latency with reliability weighting";

  select(pool, context) {
    const healthy = pool.filter((c) => c.circuitBreakerState !== "OPEN");
    const sorted = [...healthy].sort(
      (a, b) => a.p95LatencyMs + a.errorRate * 1000 - (b.p95LatencyMs + b.errorRate * 1000)
    );
    return { provider: sorted[0].provider /* ... */ };
  }
}
```

**Ìgbà tí ó yẹ kí o lò ó**: Àwọn iṣẹ́ tí latency ṣe pàtàkì fún bíi chat gidi-gidi, autocomplete, tàbí àwọn olùrànlọ́wọ́ ìkóòdù (coding assistants) tí ó jẹ́ interactive.

**Aliases**: `latency`, `fast`

---

#### 4. `sla-aware` / `sla` — latency/error/cost SLO compliance

Ó ń fún candidate kọ̀ọ̀kan ní ìṣirò nípasẹ̀ bí ó ṣe tẹ́lọ́rùn pẹ̀lú ìlànà SLO tí a ṣètò:

| Factor          | Weight | Formula                                           |
| --------------- | ------ | ------------------------------------------------- |
| Àmì ìdádúró     | 35%    | `threshold / max(value, ε)`                       |
| Àmì àṣìṣe       | 35%    | `threshold / max(value, ε)`                       |
| Àmì ìlera       | 15%    | `1.0` (CLOSED) / `0.5` (HALF_OPEN) / `0.0` (OPEN) |
| Àmì iye owó     | 10%    | `threshold / max(value, ε)` or inverse normalized |
| Àmì ìdúróṣinṣin | 5%     | inverse normalized latency stddev                 |

Nígbà tí `hardConstraints: true`, a máa ń tò àwọn olùdíje ní àkọ́kọ́ nípasẹ̀ **àmì ìrúfin**
(bí wọ́n ṣe kọjá àwọn SLO tó wà), lẹ́yìn náà nípasẹ̀ àmì àpapọ̀. Bí bẹ́ẹ̀ kọ́, àmì àpapọ̀ nìkan ni a máa ń lò.

```ts
class SLAStrategyImpl implements RouterStrategy {
  readonly name = "sla-aware";
  readonly description =
    "Selects the provider most likely to satisfy latency, error-rate, and cost SLOs";

  select(pool, context) {
    // ... scores each candidate against policy: { targetP95Ms, maxErrorRate, maxCostPer1MTokens, hardConstraints }
  }
}
```

**Àwọn pápá SLA** (tí a ṣètò lórí ìtòlẹ́sẹẹsẹ combo):

```json
{
  "strategy": "auto",
  "config": {
    "routerStrategy": "sla-aware",
    "slaTargetP95Ms": 1500,
    "slaMaxErrorRate": 0.05,
    "slaMaxCostPer1MTokens": 5,
    "slaHardConstraints": true
  }
}
```

**Nígbà tí a ó lò ó**: Àwọn iṣẹ́ tó wà ní ìpele ìṣelọ́ pẹ̀lú ìdádúró tó múná dọ́kọ́, ìwọ̀n àṣìṣe, tàbí ìṣúná iye owó.

**Àwọn orúkọ mìíràn**: `sla-aware`, `sla`

---

#### 5. `lkgp` — olùpèsè tó kẹ́yìn tí ó dára ní àkọ́kọ́

Ó máa ń gbìyànjú **olùpèsè tó kẹ́yìn tí ó dára** (tí a bá ṣètò rẹ̀) ní àkọ́kọ́, lẹ́yìn náà ó padà sí ọ̀nà ìdarí
`rules`. Ó wúlò fún ìdúróṣinṣin ìgbà ìjíròrọ̀ — olùpèsè kan náà ló máa ń ṣàkóso àwọn ìbéèrè tó tẹ̀ lé e nínú ìjíròrọ̀ kan.

```ts
class LKGPStrategyImpl implements RouterStrategy {
  readonly name = "lkgp";
  readonly description = "Tries last known good provider first, then falls back to rules";

  select(pool, context) {
    if (context.lkgpEnabled === false) {
      return getStrategy("rules").select(pool, context);
    }

    if (context.lastKnownGoodProvider) {
      const candidates = pool.filter(
        (c) => c.provider === context.lastKnownGoodProvider && c.circuitBreakerState !== "OPEN"
      );
      if (candidates.length > 0) {
        return { provider: candidates[0].provider /* ... */ };
      }
    }

    // Fallback to rules strategy
    return getStrategy("rules").select(pool, context);
  }
}
```

**Nígbà tí a ó lò ó**: Àwọn ìjíròrọ̀ tó ní ìpele púpọ̀ níbi tí o ti fẹ́ kí olùpèsè kan náà ṣàkóso
àwọn ìbéèrè tó tẹ̀ lé e (fún àpẹẹrẹ, fún caching, ìtẹ̀síwájú ọ̀rọ̀, tàbí ìbámu iye owó).

**Orúkọ mìíràn**: `lkgp` (kò sí orúkọ mìíràn)

---

#### 6. `nadir` — yíyàn àwòṣe tó mọ̀ nípa ìtọ́ni nípasẹ̀ Nadir

Gbogbo ọ̀nà ìdarí tó wà lókè yìí ló máa ń tò àwọn olùdíje nípasẹ̀ telemetry tiwọn; kò sí èyíkéyìí nínú wọn tó máa ń ka ìbéèrè náà. `nadir` máa ń fi ìgbésẹ̀ olùlo tó kẹ́yìn pẹ̀lú àwọn id àwòṣe ti adágún náà ránṣẹ́ sí API ìpinnu [Nadir](https://getnadir.com) (`POST /v1/bucket`) ó sì máa ń darí sí àwòṣe tí Nadir bá yàn láti inú àkojọ náà (`simple` → àwòṣe tó gbajúmọ̀ jùlọ tí ó sì rówó, `complex` → èyí tó wà ní iwájú). Ọ̀nà ìsopọ̀ tó ń ṣiṣẹ́ fún àwòṣe yẹn ni `rules` ṣì máa ń yàn, nítorí náà quota, ìlera, àti iye owó ló ṣì ń pinnu àkọọ́lẹ̀ wo ni yóò ṣiṣẹ́.

```json
{
  "strategy": "auto",
  "config": {
    "routerStrategy": "nadir",
    "nadir": {
      "apiKey": "ndr_...",
      "baseUrl": "https://api.getnadir.com",
      "timeoutMs": 2000
    }
  }
}
```

`OMNIROUTE_NADIR_API_KEY` àti `OMNIROUTE_NADIR_BASE_URL` ni àwọn ìpadàsẹ́yìn env fún àwọn
ọ̀rọ̀ méjì náà. `baseUrl` nìkan ni a nílò fún Nadir tí a gbàlejò fúnra ẹni (a gba `/v1` tó bá wà ní ìparí).
Àwọn ìpè tí kò ní kọ́kọ́rọ́ máa ń wá sí ìpele àìlórúkọ ti Nadir, èyí tí ó ní ìwọ̀n ìṣẹ́ fún IP kọ̀ọ̀kan.

Ohun tó ń jáde kúrò nínú àpótí náà: ọ̀rọ̀ ìfẹ́ránṣẹ́ olùlo tó kẹ́yìn (àwọn lẹ́tà 16k àkọ́kọ́), àwọn id àwòṣe olùdíje àti àmì ikanni `source: "omniroute"`. Kò sí ìtọ́ni ètò, ìtàn, àwọn irinṣẹ́ tàbí àwọn àkọlé.

Ìhùwàsí ìkùnà ni fail-open: àkókò tó kọjá (ìbẹ̀rẹ̀pẹ̀pẹ̀ 2000 ms), àìjẹ́ 2xx, ògùṣọ̀ tí a kò lè dé ọ̀dọ̀ rẹ̀, ìdáhùn tí kò tọ́ tàbí yíyàn tó wà níta adágún náà yóò yọrí sí ìpinnu `rules` àti pé a fi `NadirStrategy: fallback (…)` ṣáájú ìdí rẹ̀. Lẹ́yìn ìpè tó kùnà, ọ̀nà ìdarí náà máa ń fò àwọn nẹ́tíwọ́ọ̀kì kọjá fún 30 s, nítorí náà ìdádúró kan máa ń ná àkókò ìdádúró kan fún 30 s dípò ọ̀kan fún ìbéèrè kọ̀ọ̀kan. Àwọn ìṣẹ̀lẹ̀ ìdarí máa ń ròyìn `strategy: "nadir"` nígbà tí Nadir bá ṣe yíyàn náà gan-an.

**Nígbà tí a ó lò ó**: àwọn ìròkẹ̀ tó ní ìṣòro onírúurú lórí adágún tó gba àwọn ìpele àwòṣe (kékèké, àárín, àti àwòṣe tó wà ní iwájú), níbi tí àwòṣe tó wà ní iwájú nígbà gbogbo jẹ́ iye owó tí o fẹ́ dín kù.

**Orúkọ mìíràn**: `nadir` (kò sí orúkọ mìíràn)

---

### Àwọn ọ̀nà ìdarí olùdarí tí a ṣe àkànṣe

O le forúkọ sílẹ̀ fún ìṣe `RouterStrategy` tirẹ nípasẹ̀ API gbogbogbò:

```ts
import {
  registerStrategy,
  type RouterStrategy,
} from "@omniroute/open-sse/services/autoCombo/routerStrategy";

class MyCustomStrategy implements RouterStrategy {
  readonly name = "my-custom";
  readonly description = "My custom routing strategy";

  select(pool, context) {
    // Your routing logic here
    return {
      provider: pool[0].provider,
      model: pool[0].model,
      strategy: this.name,
      reason: "MyCustomStrategy: ...",
      candidatesConsidered: pool.length,
      finalScore: 1.0,
    };
  }
}

registerStrategy("my-custom", new MyCustomStrategy());
```

Lẹ́yìn náà lò ó:

```json
{
  "strategy": "auto",
  "config": {
    "routerStrategy": "my-custom"
  }
}
```

## Ìbámu fún Iṣẹ́

A ti ṣe àgbéyẹ̀wò àwọn model tó ju 30 lọ kọjá oríṣi iṣẹ́ mẹ́fà (`coding`, `review`, `planning`, `analysis`, `debugging`, `documentation`). Ó ṣe àtìlẹ́yìn fún àwọn àpẹẹrẹ wildcard (fún àpẹẹrẹ, `*-coder` → àmì coding gíga).

## Àkótán Àwọn Auto Variants

Pẹ̀lú `auto` lásán (àìyípadà) àti àwọn iye `AutoVariant` mẹ́fà tí a kéde nínú `autoPrefix.ts`, **ID model méje tí a lè pè** ló wà:

`auto`, `auto/coding`, `auto/fast`, `auto/cheap`, `auto/offline`, `auto/smart`, `auto/lkgp`

(`AutoVariant` fúnra rẹ̀ ṣe àkójọ iye mẹ́fà; àṣàyàn keje ni “kò sí variant” — `auto` lásán — tí `parseAutoPrefix()` ń ṣàkóso gẹ́gẹ́ bí `variant: undefined`.)

## Bí àwọn ipele ṣe bá Auto-Combo mu

Ìṣẹ́ ìṣírò olùfihàn 16 (`open-sse/services/autoCombo/scoring.ts`) ka jíjẹ́ ọmọ ẹgbẹ́ ipele sí àmì méjì: `tierPriority` (0.0476) àti `tierAffinity` (0.0476). Wo [tábìlì ìfosiwewe ìṣírò](#how-it-works-persisted-auto-combos) àṣẹlétò lókè fún gbogbo àkójọpọ̀ `DEFAULT_WEIGHTS` — àwọn àtúnṣe ti ìdìpọ̀ kọ̀ọ̀kan (ship-fast/cost-saver/quality-first/
offline-friendly) wà nínú tábìlì "Àwọn prófáìlì ìwọ̀n fún ìdìpọ̀ kọ̀ọ̀kan".

Ipele nìkan **kì í** fipá mú Ipele 1 láti kọ́kọ́ wá — bí ìdádúró Ipele 1 bá burú tàbí ìwọ̀ntúnwọ̀nsì iye-owó-sí-dídára kò bá dára jù, Ipele 2 ló máa borí. Láti fipá mú ìtẹ̀lé ipele, lo ọgbọ́n àkójọpọ̀ `priority`, kí o sì ṣètò àwọn olupèsè ní ìbámu pẹ̀lú ipele wọn.

Láti ṣe ojúrere tó lágbára fún Ipele 1 (ìforúkọsílẹ̀), mú ìwọ̀n `tierPriority` pọ̀ sí i:

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "tierPriority": 0.3, "costInv": 0.05 } } }
}
```

Wo [`docs/guides/TIERS.md`](../guides/TIERS.md) fún àwọn ìtumọ̀ ipele àti ìsọ̀rí àwọn olupèsè.

### Matrix ìpinnu routing tí kò yípadà (`npm run test:combo:matrix`)

`tests/integration/combo-matrix/*.test.ts` fi ìpinnu routing gbogbo ọgbọ́n gbogbogbò 19 hàn láti ìbẹ̀rẹ̀ dé òpin nípasẹ̀ pipeline combo gidi pẹ̀lú upstream àfarawé.
Ìbojú náà ní:

- Gbogbo ọgbọ́n `ROUTING_STRATEGY_VALUES` 19 (ordered, weighted, cost, context, fusion, …).
- `quota-share` (ti inú) láti ìbẹ̀rẹ̀ dé òpin: ìdájọ́ òdodo DRR + fífi ohun tó ti kún jù sí ipò kékeré nípasẹ̀ seam `selectQuotaShareTarget` gidi (`registerQuotaFetcher` / `setLKGP` /
  `__setHeadroomSaturationFetcherForTests`).
- Ìbojú `context-relay` universal-handoff kọjá gbogbo iye target.

Suite yìí ń ṣiṣẹ́ nínú CI (iṣẹ́ `test:integration`) pẹ̀lú `--test-concurrency=1` àti
`--test-force-exit`, kí ó lè máa fúnni ní àbájáde kan náà, kí ó sì má nílò credentials tó ń ṣiṣẹ́.
